코드로 AI 모션 영상 만드는 원리와 방법

요즘 AI가 만드는 모션 영상은 영상 생성 모델이 아니라 코드로 그린 경우가 많아요. 브라우저가 코드를 그림으로 그리는 원리, 끊김 없이 MP4로 뽑는 방법, aimotion 스킬 설치와 기법 가져다 쓰는 법, 장점과 한계까지.

요즘 SNS에서 보이는 매끈한 모션 영상 중에는 영상 생성 AI가 아니라 코딩 AI가 코드로 그린 것이 많아요. 점이 물결처럼 퍼지고, 글자가 젤리처럼 출렁이고, 로고가 금속처럼 반짝이는 장면도 이미지 한 장 없이 코드만으로 나와요. 코드를 몰라도 괜찮아요. 코드는 AI가 짜고, 우리는 무엇을 만들지와 어떤 기법을 쓸지만 정하면 됩니다.

이 글은 유튜브 '코드깎는노인'의 영상 AI 모션 영상, 실제로는 이렇게 만듭니다와 그가 공개한 오픈소스 aimotion을 바탕으로, 직접 써 보며 정리했어요. 기법 166편은 코드 모션 기법 목록에서 데모로 볼 수 있어요.

1. 코드가 어떻게 영상이 될까

  1. 브라우저는 코드를 그림으로 그리는 프로그램이에요. "여기에 동그라미 하나"라고 적으면 화면에 동그라미가 나와요.
  2. 숫자를 바꾸며 다시 그리면 움직여요. 동그라미의 가로 위치를 숫자 하나로 정해 두고 그 숫자를 조금씩 바꿔 매번 다시 그리면, 동그라미가 움직이기 시작해요.
  3. 영상은 1초에 30장(많게는 60장) 넘어가는 그림이에요. 그러니 영상을 만든다는 건, 시각마다 그림 한 장을 정확히 그려 내는 일이에요.
  4. 모든 움직임을 '시각 t' 하나로 계산해요. 같은 t를 넣으면 언제나 같은 그림이 나오게 짜 두면, 어느 순간으로 건너뛰어도 똑같은 장면이 나와요.
  5. 실시간 재생 대신 한 장씩 찍어 이어 붙여요. 브라우저에서 실시간으로 돌리면 무거운 장면에서 프레임이 빠지기도 해요. 그래서 시계를 1/30초씩 옮기며 한 장씩 그리고, 다 그려지면 캡처해 차례로 MP4로 합쳐요. 한 장에 몇 초가 걸려도 결과는 끊김 없이 부드러워요.
이 장면을 HTML 한 장으로 만들어 줘. 모든 움직임은 render(t) 함수 하나로 계산해서 같은 t엔 같은 그림이 나오게 하고,
Playwright로 t를 1/30초씩 옮기며 1080×1920 프레임을 캡처한 뒤 ffmpeg로 30fps MP4를 만들어 줘.

이 '프레임 단위 렌더링'을 대신 해 주는 도구도 있어요(HyperFrames, Remotion 등). 어떤 도구를 쓰든 원리는 같아요.

2. 코드로 어디까지 만들 수 있을까

생각보다 훨씬 넓어요. aimotion은 기법을 12개 분류로 나눠 데모 166편을 담았어요.

분류예시
웹 그래픽 기법먹 번짐(SVG 필터), 성운 · 오로라(셰이더), 물속 잉크(유체 계산), 파티클
아날로그 표현수채화, 유화, 목판화, 리소그래프, 8mm 필름, VHS, 종이 스톱모션, 붓글씨, 네온
실험 타이포그래피말랑한 글자, 타는 글자, 빛으로 쓴 글자, 김 서린 창에 쓴 글자
타이포그래피 모션그래픽말하는 자막, 예능 자막, 손글씨 쓰기, 플랩 전광판, 한글 조합, 글자 뒤 피사체
모션그래픽 디자인로고 리빌, 앱 소개, 방송 그래픽, 지도 경로, 통계 아이콘, 메신저 대화
영상 표현력표정 리그 · 립싱크, 장면 전환, 사진 시차(2.5D), 스케일 줌, 전후 비교, 불릿 타임
3D 장면제품 턴테이블, 분해도, 툰 셰이딩, 틸트시프트 미니어처, 지구본 경로

예를 들어 '물속 잉크'는 화면을 작은 칸으로 나눠 칸마다 물의 속도를 담고, 힘 더하기 → 압력 맞추기 → 흐름 따라 잉크 옮기기를 되풀이해 만들어요. '종이 인형극'은 일부러 1초에 12번만 그림을 바꾸고 가장자리를 짧은 직선으로 끊어 손으로 오린 느낌을 내요. '새벽 호숫가'는 사진 한 장에 깊이 지도를 더해 가까운 것은 많이, 먼 것은 조금 움직이는 2.5D 시차예요. 원리는 복잡하지만, 다 알아야 만들 수 있는 건 아니에요. 코드는 에이전트가 짜니까요.

3. 직접 만들어 보기: Claude Code

  1. 빈 폴더를 하나 만들고 그 안에서 Claude Code를 실행해요.
  2. 만들고 싶은 장면을 말로 적어요. 예: "물속에 잉크가 번지듯 나타나는 제목을 6초짜리 세로 영상으로 만들어 줘."
  3. 결과를 보고 고칠 점을 말로 알려 줘요. 코드를 짜고, 고치고, 렌더링해 확인하는 일은 에이전트가 해요. 처음부터 원하는 그림이 나오진 않으니 몇 번 왕복할 각오를 하세요.

4. 기법을 가져다 쓰기: aimotion 스킬

aimotion은 기법 하나마다 짧은 데모 하나와 구현 노트(몇 초에 무엇이 보이는지, 어떤 원리인지, 소스의 몇 번째 줄인지)와 소스 전체를 묶은 Claude Code 스킬이에요. 설치해 두면 에이전트가 장면에 필요한 기법을 스스로 찾아 원리를 읽고 그 기술만 가져다 써요.

claude plugin marketplace add kstost/cokacmotion
claude plugin install aimotion@aimotion

Claude Code 안에서는 /plugin marketplace add kstost/cokacmotion, /plugin install aimotion@aimotion으로 설치해요. 설치가 번거로우면 요청할 때 저장소 주소를 같이 적어도 돼요. 에이전트가 저장소를 받아 안내 문서부터 읽어요.

쓰는 방법은 데모를 짚어 주는 것뿐이에요.

aimotion의 98-split-flap 기법만 참고해서, 우리 카페 '오늘의 메뉴' 3가지를 공항 전광판처럼 보여 주는 6초 세로 영상을 만들어 줘.
데모의 장면 · 문구 · 색은 쓰지 말고 원리만 가져와.

중요한 규칙: 데모에서 가져오는 건 기술(효과를 만드는 원리와 구현)뿐이에요. 데모의 소재 · 장면 · 문구 · 색 · 구도를 그대로 옮기면 안 돼요. aimotion 스킬 자체에도 이 규칙이 가장 먼저 적혀 있어요. 코드 모션 기법 목록의 '프롬프트 복사' 버튼에는 이 규칙이 미리 들어 있어요.

5. 코드로 만든 영상, 좋은 점과 어려운 점

좋은 점어려운 점
글자가 진짜 글자라 4K로 키워도 선명하고, 한글이 깨지지 않아요브라우저에서 바로 볼 때는 매 프레임을 실시간으로 그려야 해서 무거운 장면은 버벅여요(미리 굽거나 해상도를 낮춰요)
대본이 바뀌면 시간표만 다시 뽑으면 되고, 몇 번을 다시 만들어도 같은 결과가 나와요그래픽 카드를 많이 쓰는 장면은 한꺼번에 여러 개 띄우기 어려워요
코드라서 무엇을 고쳤는지 줄 단위로 비교하고 언제든 되돌릴 수 있어요. 영상을 문서처럼 다뤄요에이전트도 처음부터 원하는 그림을 내지는 못해서, 보고 말로 고치는 왕복이 몇 번 필요해요

실사 인물이나 자연스러운 풍경은 여전히 영상 생성 AI(클링 · Veo · 시댄스 등)가 잘해요. 그래서 실사 컷은 영상 AI로, 제목 · 자막 · 숫자 · 로고 · 그래픽은 코드로 만들어 합치는 방식이 가장 효율적이에요.

자주 묻는 질문

코딩을 전혀 몰라도 만들 수 있나요?

네. 코드는 Claude Code 같은 코딩 에이전트가 짜요. 만들고 싶은 장면을 말로 설명하고, 결과를 보며 고칠 점을 말로 알려 주면 돼요.

aimotion은 무료인가요?

네. MIT 라이선스로 공개된 오픈소스라 무료로 쓸 수 있고, 기법을 구현한 코드는 옮겨 써도 돼요. 다만 데모가 그린 장면 · 문구 · 색은 기법을 보여 주는 예시라서 영상에는 원리만 가져다 써야 해요.

영상 생성 AI와 무엇이 다른가요?

영상 생성 AI는 학습한 영상과 비슷한 화면을 새로 만들어 내고, 코드 모션은 수식과 규칙으로 화면을 정확히 그려요. 그래서 코드 모션은 글자 · 숫자 · 로고가 깨지지 않고 몇 번을 다시 만들어도 같은 결과가 나와요. 실사 인물과 풍경은 영상 생성 AI가 더 잘해요.

만든 영상을 MP4로 어떻게 받나요?

에이전트에게 "render(t)로 1/30초마다 프레임을 캡처해 MP4로 합쳐 줘"라고 하면 돼요. 실시간 화면 녹화보다 끊김이 없고 화질도 좋아요.
