제품·앱 소개로 쓸 때

제품·앱·서비스의 생김새나 기능을 보여 주는 장면에 써요.

  • 실제 제품 사진(배경 제거 PNG)이나 앱 화면 캡처를 함께 주면 그대로 넣어 움직여요.
  • 기능 하나당 2–3초, 한 화면에 한 가지만 보여 주세요.
  • 가격·혜택 같은 숫자는 코드로 넣어야 깨지지 않아요.

사전 카드와 함께 쓰기

G02 화면 속 다이브 카드와 같은 기법이에요. 카드의 예시 영상과 주문서 기능을 같이 써 보세요.

만드는 법

  1. 준비하기

    Claude Code를 열고 빈 폴더에서 시작해요. aimotion 스킬을 처음 한 번 설치해요.

    claude plugin marketplace add kstost/cokacmotion claude plugin install aimotion@aimotion

  2. 프롬프트 만들기

    칸을 채우면 아래 프롬프트가 바로 바뀌어요. 데모의 장면이 아니라 내 장면을 적는 게 핵심이에요.

  3. 미리보기 보고 고치기

    Claude Code가 만든 HTML을 브라우저로 열어 확인하고, 고칠 점을 말로 알려 줘요. 자주 쓰는 수정 문장을 눌러 복사하세요.

  4. MP4로 뽑기

    실시간 화면 녹화보다 프레임 단위 렌더링이 끊김 없고 선명해요.

    이제 render(t)로 1/30초마다 프레임을 캡처해서 30fps MP4로 렌더링해 줘. 결과 파일 이름은 out.mp4로.

  5. 내 영상에 합치기

    제목 · 자막 · 전환처럼 실사 위에 얹을 효과라면 배경을 투명하게 뽑아 편집 프로그램(캡컷 · 프리미어)의 위 트랙에 올려요. 이미 찍은 영상이 있으면 파일을 주고 "이 영상 위에 효과를 입혀 줘"라고 해도 돼요.

    배경을 투명하게 해서 알파 채널이 있는 영상(ProRes 4444 .mov 또는 WebM)으로도 뽑아 줘.

초 단위로 보기

데모가 몇 초에 무엇을 보여 주는지예요. 장면을 따라 하려는 게 아니라, 기법이 어떤 순서와 리듬으로 쓰였는지 보는 용도예요.

미감은 밝은 플랫 일러스트 앱 광고다. 바탕은 세이지 종이색이고, 가장자리에 흐린 몬스테라 잎 두 겹과 떠다니는 물방울 보케, 필름 그레인을 깔았다. 아래에는 자막용 짙은 초록 바닥 띠가 있다. 색은 먹초록(#17352a)과 물빛 파랑(#2c7bf2) 하나만 쓴다. 글꼴은 Pretendard 하나다. 글자는 두 층으로 나뉜다. - UI 글자(화면 안): 13–32px. 날짜·제목·카드 이름·메타·알약·탭 이름처럼 실제 앱의 위계를 따른다. 숫자는 고정폭이다. - 홍보 글자(화면 밖): 헤드라인은 88px 800, 자간 −0.035em. 번호 알약(01)과 라벨 29px이 붙고, 핵심어 하나만 파랑이다.

시간 장면 움직임
0–2.0 홈: "오늘 물 줄 식물 2", 이번 주 물주기 5/7 카드, 식물 카드 넷과 "+ 새 식물 들이기" 기기가 아래에서 크게 기울어진 채 솟아(expo.out) 왼쪽을 보는 3/4 자세로 선다. 홈 요소가 위에서부터 겹쳐 들어오고 5/7이 센다. 콜아웃 01 오늘 할 일 — "오늘 물 줄 식물, / 한눈에 쏙": 헤드라인이 줄 마스크에서 올라오고, 지시선이 내려와 꺾여 몬스테라 썸네일의 원형 초점 틀에 닿는다. 1.84초에 터치가 카드를 누른다.
2.0–4.1 상세(공유 요소 전환) 카드의 사각형이 그대로 커져 전체 화면이 되고(컨테이너 트랜스폼), 썸네일은 히어로 그림으로, 카드 이름은 제목으로 날아간다. 목록은 뒤로 물러나 어두워진다. 그사이 기기는 반대쪽 3/4(오른쪽을 봄, 24°)로 돈다. 칸들이 차례로 들어오고 함께한 날 214·물 준 횟수 31·새 잎 3·흙 수분 18%가 센다. 콜아웃 02 흙 수분 체크 — "목마른 정도를 / 숫자로 딱"이 18%를 둥근 사각 틀로 짚는다.
4.1–5.2 물 줬어요(큰 박자) 기기가 정면으로 돌아온다. 버튼을 누르면 손끝 고리와 버튼 안 잉크 물결이 퍼지고, 기기가 살짝 튕긴다. 게이지가 18→72%로 차고, 물 준 횟수가 32로 튀며, 상태 알약이 '목말라요'에서 '촉촉해요'로 바뀐다. 버튼은 '기록했어요 ✓'로 바뀐다. 물방울 18개가 화면 밖으로 튀어나오며 커진다(카메라 쪽으로 오는 느낌).
4.9–6.5 바텀 시트 화면이 어두워지고 시트가 조금 넘치며 올라온다. "다음 물주기 7월 12일 토요일", 요일 칩 일곱이 물결처럼 들어오고 12일이 튀어 켜진다. 알림 줄과 버튼이 뒤따른다. 기기는 다시 왼쪽 3/4로 눕듯 기운다. 콜아웃 03 물주기 알림 — "톡 한 번이면 / 알림까지 끝"이 알림 줄을 짚는다. 6.26초에 '알림 맞추기'를 누르면 시트가 떨어진다.
6.4–8.1 탭 전환 터치가 떨어지지 않고 세그먼트 탭 '기록'까지 미끄러져 가서 누른다. 흰 표시가 옆으로 미끄러지고, 내용이 통째로 옆으로 밀려 '키 성장' 차트가 들어온다. 막대 여덟 개가 차례로 솟고 61cm가 센다. 기기는 오른쪽 3/4. 콜아웃 04 성장 기록 — "자라는 시간도 / 차곡차곡"이 이번 달 막대를 짚는다.
8.2–10 엔드 카드 기기가 뒤로 누우며 화면 아래로 내려가 짙은 바닥 띠에 반쯤 잠긴다. 아이콘 자리에서 옅은 물빛이 원으로 번져 색온도가 세이지에서 물빛으로 바뀐다. 앱 아이콘(물방울 속 새싹)이 튀어나오며 고리 둘이 퍼진다. 촉촉(224px 900)이 글자마다 마스크에서 올라오고, "목마르기 전에, 먼저 알려 줄게요"와 배지("무료로 시작하기 / 지금 받기")가 뒤따른다. 9.4초에 터치가 배지의 화살표를 누른다.

절정 포스터는 render.mjs 기본 시각(0.6·D = 6.0초)이다. 3/4로 기운 기기, 올라온 시트, 콜아웃 03의 헤드라인·지시선·초점 틀이 한 화면에 다 있다.

원리

개발자용 구현 설명이에요(원작자 노트, MIT). 몰라도 만들 수 있지만, Claude에게 "이 원리 중 ○○만 써 줘"처럼 지시할 때 도움이 돼요.

기법과 원리
  • 이야기 시계 한 곳: 장면 시각은 T(main.js:41), 터치의 방문 지점과 누름 시각은 TAPS(main.js:44), 콜아웃 문구·초점 틀은 CO(main.js:53)에 있다. 타임라인과 닫힌 식이 모두 이 표를 읽는다.
  • 기기 = CSS 3D 리그(main.js:412, style.css의 .cam·.rig)
  • .cam에 perspective: 2400px을 주고, .rig(transform-style: preserve-3d) 안에 판 12장을 3.4px 간격 translateZ로 쌓았다. 그래서 3/4로 돌면 41px 두께의 옆면이 보인다. 판 색은 가운데 깊이가 밝아 금속 띠처럼 보이고, 가운데 판들에만 옆 버튼 하나를 달았다.
  • 그 위에 본체(베젤)와 화면이 있다. 그림자 판은 −110px 뒤에 흐리게 둬서 기기와 함께 기운다.
  • 자세는 GSAP이 프록시 P = {x, y, rx, ry, rz, s}를 트윈하고, frame이 느린 떠다님(y ±9px, rx ±1.1°, ry ±1.6°)과 물 박자의 감쇠 펀치를 더해 translate3d · rotateX · rotateY · rotateZ · scale3d 한 줄로 쓴다(main.js:587-597).
  • 화면 유리 반사(.glare)는 ry·rx에 따라 배경 위치가 옮겨 간다.
  • 3D 투영으로 지시선 찾기(main.js:252, project): CSS가 쓰는 것과 같은 변환(크기 → rotateZ → rotateY → rotateX → 이동 → 원근 w = 1 − z/P)을 JS로 다시 계산해, 화면 좌표의 UI 점이 무대 어디에 보이는지 구한다.
  • 지시선(leaderD, main.js:300)은 헤드라인 아래 점에서 수직으로 내려와 반지름 30px로 꺾인 뒤 초점 틀의 가장자리까지 간다. 진행률 p로 잘라 그린다.
  • 초점 틀(frameD, main.js:323)은 화면 평면 위 둥근 사각형을 한 점씩 투영한 경로다. 그래서 기기가 기울면 틀도 원근대로 기운다. 원형(썸네일)부터 긴 줄(알림 줄)까지 같은 함수로 그린다.
  • 맥박 틀은 0.95초마다 20px 부풀며 사라진다. 기기가 떠다니고 돌아도 지시선 끝은 매 프레임 UI 위에 붙어 있다(main.js:637-659).
  • 화면 전환은 UI의 논리를 따른다
  • 공유 요소(컨테이너 트랜스폼)(main.js:504): 상세 화면 전체에 clip-path: inset(카드 사각형 round 22px)을 씌우고, 0.6초 동안 inset(0 round 54px)까지 연다. 처음 0.14초에는 카드의 메타·알약 복사본을 지운다. 히어로(290px 원)는 썸네일 자리에서 scale 64/290으로 출발하고, 제목은 카드 이름 자리에서 scale 18/32로 출발한다. 둘은 같은 곡선으로 날아간다. 목록은 0.93으로 물러나며 어두워진다. GSAP Flip(69번)은 쓰지 않았다. 좌표를 직접 설계한 레이아웃에서 시작·끝 변환을 손으로 정했다.
  • 시트(main.js:542): 배경 막이 어두워지고 시트가 back.out(1.05)로 조금 넘치며 올라온다. 내용은 0.045초 간격으로 겹쳐 들어온다. 퇴장(power2.in 0.32초)은 등장보다 빠르다.
  • 탭 전환(main.js:555): 세그먼트 표시가 141px 옆으로 가고, 두 창이 같은 곡선으로 476px씩 밀린다(나가는 창과 들어오는 창이 붙어 있음). 막대는 scaleY 0.05초 간격으로 솟는다.
  • 터치 표시(touch, main.js:273; press, main.js:267): 반투명 회색 원과 흰 테두리라서 흰 카드 위에서도 파란 버튼 위에서도 보인다.
  • 나타남(1.45→1배), 누름(0.82배까지 outCubic), 놓음(outBack으로 살짝 넘침), 사라짐이 모두 방문 표에서 나오는 닫힌 식이다.
  • 놓는 순간 손끝 고리(ringAt)와 눌린 요소 안의 잉크 물결(rippleAt, 요소의 overflow: hidden이 자른다)이 퍼진다. 눌린 요소는 CSS 독립 속성 scale로 3% 들어간다. GSAP이 쓰는 transform과 부딪히지 않는다.
  • 세 번째 방문은 사라지지 않고 다음 지점으로 미끄러진다(g). 손가락을 떼지 않고 옮겨 가는 흔한 시연 문법이다.
  • 세는 숫자: GSAP이 프록시 N을 트윈하고 frame이 반올림해 고정폭 숫자로 쓴다(main.js:599-608). 바뀐 글자만 DOM에 쓴다. 게이지 너비와 5/7 막대도 같은 값을 읽는다.
  • 콜아웃 등장·퇴장(main.js:493)
  • 등장: 라벨이 옆에서 들어온다(expo.out). 헤드라인 두 줄은 줄 마스크 안에서 0.1초 간격으로 올라온다. 0.3초 뒤 지시선이 0.42초 동안 그려지고, 틀이 back.out(2.2)로 열린다.
  • 퇴장은 0.3초 power2.in이다. 줄이 위로 빠지면서 투명해져 마스크 끝에 글자 조각이 남지 않는다.
  • 헤드라인은 1.0–1.3초 동안 멈춰 있어서 한 줄에 0.5초 이상 읽을 시간이 있다. 왼쪽·오른쪽 콜아웃을 번갈아 쓰고, 기기는 늘 콜아웃 쪽을 보도록 반대편으로 비켜 선다.
  • 물방울(main.js:438, main.js:661): 눈물방울 모양 18개다. 위치는 공기 저항이 있는 탄도의 닫힌 식 x = v/k·(1 − e^(−k s))에 중력을 더해 구한다. 뾰족한 끝은 속도 반대쪽을 향하고, 크기는 시간에 따라 1.8배까지 커진다. 버튼에서 물빛 고리 하나가 퍼진다.
  • 엔드 카드(main.js:568, main.js:680-704)
  • 물빛 원 와이프(dyn 캔버스)로 색온도를 바꾼다. 아이콘은 회전하며 튀어나오고 고리 둘이 퍼진다. 앱 이름은 음절마다 마스크에서 올라온다(자간 0, 마스크 여백을 겹쳐 획이 잘리지 않음).
  • 배지는 직접 디자인했다. 짙은 초록 알약에 기기+화살표 글리프, 두 줄 글, 파란 화살표 단추가 있다. 실제 스토어 배지 모양은 따르지 않았다.
  • 배경(main.js:338, paintLeaf)
  • 몬스테라 잎은 하트 모양 경로에 갈라진 틈 셋을 destination-out으로 낸 것이다. setup에서 원경(blur 10)과 중경(blur 1.5) 캔버스에 한 번 그리고, frame에서는 기기 위치의 반대로 미는 시차만 준다.
  • 보케 30개는 닫힌 식으로 떠오른다. 그레인은 540×960 노이즈를 두 배로 키워 5% 불투명도로 덮는다.
  • 화면 속 식물 그림(몬스테라·바질·스투키·고무나무, main.js:105)은 SVG 평면 일러스트다. 몬스테라의 틈은 잎 좌표계 마스크로 뚫는다.

  • 움직임은 gsap.timeline({ paused: true, defaults: { lazy: false } }) 하나에 있다(main.js:478). frame은 tl.time(t)을 먼저 부른다.
  • 속성마다 첫 트윈은 fromTo이고 그다음은 to다. 같은 속성의 트윈이 시간상 겹치지 않게 짰다. setup 끝에서 tl.time(D); tl.time(0)으로 모든 트윈을 순서대로 한 번 초기화한다(main.js:577).
  • 보였다 안 보였다 하는 전환은 길이 0인 set 대신 1ms autoAlpha 트윈이다.
  • 터치·고리·물결·누름·떠다님·펀치·물방울·보케·지시선·초점 틀·엔드 고리는 모두 t의 닫힌 식이다. 다른 효과가 끝나기를 기다리는 것은 없다.
  • 지시선 끝점은 frame이 정한 자세에서 다시 계산한다. 레이아웃을 읽지 않는다(getBoundingClientRect 없음).
  • 난수는 rand(12201)(보케), rand(12202)(물방울), rand(12203)(그레인)뿐이고 모두 setup에서 뽑는다.
  • 배경 캔버스(바탕·잎 두 겹·그레인)는 setup에서 한 번 그린 정지 그림이다. 매 프레임 그리는 dyn 캔버스는 헤드리스에서 CPU 래스터(willReadFrequently)로 만든다. 그리기 전에 변환·알파·합성·필터를 기본값으로 되돌린다.
  • 렌더러 검사(정순, 새 페이지 역순, 되돌아가기): 최대 1/255 차이로 통과(허용 4). 3D 합성 경계의 반올림으로 보인다.
한계와 조절할 점
  • 두께는 판 쌓기다: 판 12장의 가장자리가 옆면을 이룬다. 24° 정도까지는 이어진 면으로 보이지만, 더 크게 돌리면(40° 이상) 계단이 보일 수 있다. 그때는 판 수를 늘리거나 판 간격(SLAB_STEP, main.js:35)을 줄인다.
  • 초점 틀의 크기는 손으로 잰 값이다: CO[].box(main.js:53)는 UI 좌표를 보고 정했다. UI 글꼴·배치를 바꾸면 함께 고쳐야 한다. 측정해서 자동으로 맞추려면 setup에서 한 번 DOM을 재서 표에 넣으면 된다(frame에서는 재지 않는다).
  • 그림자: 그림자 판은 기기에 붙어 함께 기우는 근사다. 배경 면에 드리우는 진짜 그림자(투영)는 아니다.
  • 읽기 시간: 10초에 기능 넷과 엔드 카드를 넣어서 헤드라인 하나가 1.0–1.3초 머문다. 더 여유롭게 하려면 D를 늘리고 T의 간격을 넓힌다. 콜아웃 하나를 빼도 된다.
  • 조정 손잡이: 기기 자세는 각 tl.to(P, …)(main.js:483-575)에서, 떠다님 크기는 main.js:587-597에서, 원근 깊이는 PERSP·.cam의 perspective(둘이 같아야 지시선이 맞음)에서 바꾼다.
  • 다음 단계: 기기 화면에 스크롤(목록이 관성으로 흐르는 모션 블러)을 더할 수 있다. 홈 화면 탭 바로 가는 두 번째 탭 전환이나, 알림 배너가 기기 밖으로 튀어나오는 팝아웃 카드도 후보다.
