#012 · 웹 그래픽 기법

물속에 퍼지는 잉크

GPU 유체 시뮬레이션 · Stable Fluids

제목·로고장면 전환무거움 · 그래픽 카드 사용
광고 · 쇼츠에서는물속 잉크처럼 번지는 제목 · 장면 전환 (음료 · 화장품)

활용 가이드

제목·로고로 쓸 때

영상 첫 1–2초, 브랜드명이나 핵심 제목이 처음 나오는 순간에 써요.

  • 제목은 한 줄, 6–10자 안쪽이 가장 잘 보여요.
  • 기법이 끝난 뒤 0.5–1초는 글자를 멈춰 읽을 시간을 주세요.
  • 로고라면 브랜드 색 2–3개만 지정하면 나머지 톤은 AI가 맞춰요.

장면 전환로 쓸 때

장면 A에서 B로 넘어가는 0.3–1초 구간에 써요. 컷 사이 이탈을 줄여요.

  • 전환 하나를 영상 전체에 반복해 쓰면 통일감이 생겨요. 매번 다른 전환은 산만해요.
  • 앞 장면의 마지막 프레임과 다음 장면의 첫 프레임을 같이 알려 주세요.
  • 실사 영상 사이에 넣을 땐 투명 배경(알파) 영상이나 두 영상을 직접 합치는 방식으로 요청해요.

영상에 옮길 때 주의

  • 손으로 쓴 WebGL2 셰이더 — 영상 스킬의 WebGL 층(three.js 등) 위에서 다시 쓴다
  • CPU 검증 프레임당 3.2s — 그대로 옮기면 MP4 내보내기가 매우 느리다. 해상도를 낮추거나 미리 굽는다

만드는 법

  1. 준비하기

    Claude Code를 열고 빈 폴더에서 시작해요. aimotion 스킬을 처음 한 번 설치해요.

    claude plugin marketplace add kstost/cokacmotion claude plugin install aimotion@aimotion

  2. 프롬프트 만들기

    칸을 채우면 아래 프롬프트가 바로 바뀌어요. 데모의 장면이 아니라 내 장면을 적는 게 핵심이에요.

  3. 미리보기 보고 고치기

    Claude Code가 만든 HTML을 브라우저로 열어 확인하고, 고칠 점을 말로 알려 줘요. 자주 쓰는 수정 문장을 눌러 복사하세요.

  4. MP4로 뽑기

    실시간 화면 녹화보다 프레임 단위 렌더링이 끊김 없고 선명해요.

    이제 render(t)로 1/30초마다 프레임을 캡처해서 30fps MP4로 렌더링해 줘. 결과 파일 이름은 out.mp4로.

  5. 내 영상에 합치기

    제목 · 자막 · 전환처럼 실사 위에 얹을 효과라면 배경을 투명하게 뽑아 편집 프로그램(캡컷 · 프리미어)의 위 트랙에 올려요. 이미 찍은 영상이 있으면 파일을 주고 "이 영상 위에 효과를 입혀 줘"라고 해도 돼요.

    배경을 투명하게 해서 알파 채널이 있는 영상(ProRes 4444 .mov 또는 WebM)으로도 뽑아 줘.

초 단위로 보기

데모가 몇 초에 무엇을 보여 주는지예요. 장면을 따라 하려는 게 아니라, 기법이 어떤 순서와 리듬으로 쓰였는지 보는 용도예요.

수면에서 비스듬히 내려오는 빛줄기가 깊은 남청색 물속을 비추고, 맨 위에는 커스틱이 일렁이며 부유 입자가 떠다닌다. 0.5초에 왼쪽 위와 오른쪽 아래 노즐이 동시에 잉크를 짧게 쏜다. 청록 잉크와 장밋빛 잉크가 각각 버섯 모양의 와류 쌍극자(mushroom head)로 말리면서 한 직선 위를 마주 보고 다가온다. 2.6–4초가 절정이다. 두 머리가 정면으로 부딪혀 납작해지며 서로 맞물린 태극 모양이 되고, 뒤따르는 줄기는 카르만 와열처럼 작은 소용돌이를 줄줄이 말아 올린다. 부딪힌 덩어리는 옆으로 퍼져 위는 청록, 아래는 장밋빛인 물결 띠가 된다. 가장자리는 계속 말려 들어가고, 잉크는 위에서 오는 빛을 받아 윗면은 밝고 아랫면은 스스로 그림자를 진다. 4.1초에 수면 쪽에서 금빛 한 방울이 떨어져 작은 버섯이 되어 내려오고(6–9초 여운), 띠에 박히면서 세 가지 잉크가 대리석 무늬로 섞인다. 화면은 천천히 다가가고 마지막에 조금 어두워진다.

원리

개발자용 구현 설명이에요(원작자 노트, MIT). 몰라도 만들 수 있지만, Claude에게 "이 원리 중 ○○만 써 줘"처럼 지시할 때 도움이 돼요.

기법과 원리
  • 격자: 속도·압력 270×480(RG32F / R32F), 잉크 540×960(RGBA16F, 3채널 = 세 잉크). 비디오 1프레임 = 서브스텝 2회(dt = 1/60 s).
  • 서브스텝 순서(main.js:414 이하, Jos Stam / GPU Gems 38 구성): 1. 컬(curl)(main.js:55) 2. 힘(main.js:65): 와도 감금(vorticity confinement, ε=7, main.js:76) + 잉크 농도에 비례하는 약한 음의 부력 (main.js:81) + 노즐(가우시안 영역에서 속도를 목표 제트 속도로 섞기, main.js:85). 벽에서 법선 속도는 0. 3. 발산(main.js:93, 벽에서 반사) 4. 야코비 압력 30회(main.js:106). 이전 압력에 0.8을 곱해 웜스타트한다(main.js:431). 압력도 상태의 일부다. 5. 압력 기울기 빼기(main.js:115) 6. 속도의 자기 이류: semi-Lagrangian, RK2 역추적(main.js:125) 7. 잉크 이류: MacCormack(main.js:137, main.js:147). 앞으로 한 번, 결과를 거꾸로 한 번 이류해서 왕복 오차의 절반을 보정하고, 원래 주변 4텍셀의 min/max로 클램프해(main.js:163) 새 극값이 생기지 않게 막는다. 번짐이 크게 줄어 가는 필라멘트와 소용돌이가 살아난다.
  • 노즐 스크립트(main.js:23): 위치·각도·세기가 t의 순수 함수다. 짧고 강한 퍼프(쌍극자)를 쏜 뒤 약한 줄기가 이어진다. 잉크는 제트 축이 아니라 전단층(노즐 둘레의 고리)에 주로, 맥동(7 Hz, main.js:442)과 함께 주입한다(main.js:170). 유동 가시화 실험처럼, 와류가 이 띠를 감아서 소용돌이 구조가 눈에 보인다.
  • 빛(main.js:177): 270×480에서 수면 방향으로 22스텝 레이마칭을 해 잉크별 흡수(보색, main.js:313)를 누적하고, 색이 있는 투과율을 얻는다(main.js:192). 이 하나로 잉크의 자기 그림자, 겹친 잉크 아래의 색 그림자, 물속 빛줄기에 드리운 그림자(main.js:263)를 모두 처리한다.
  • 최종 셰이더(main.js:215): 잉크는 4탭 B-스플라인으로 업샘플한다. 잉크별 커버리지를 더하는 산란 모델이라서 겹친 곳이 탁해지지 않고 밝아진다(main.js:270–272). 블러된 밀도의 기울기로 부드러운 램버트 음영을 넣고(main.js:278), 두께가 두꺼울수록 산란이 늘며, 가장자리는 반투명하게 빛나고, 블룸(4× 다운샘플 + 가우시안)을 더한다. 물은 깊이 그라디언트, 빛줄기(main.js:260), 유계 커스틱(도메인 워핑 노이즈의 능선, main.js:233)이고, 잉크 위에도 커스틱 쿠키를 얹는다. 부유 입자, 톤매핑·비네트·그레인으로 마무리한다.
프레임마다 같은 그림이 나오게 하는 법 (결정성)
  • replay({ dt: 1/30, every: 30 })(main.js:414): 스텝 n은 서브스텝 2회이고, 서브스텝 시각 (2n+s)/60에서 노즐을 계산한다.
  • 상태 = 속도 + 압력 + 잉크 세 텍스처. save()는 새 텍스처 세 장에 blitFramebuffer로 GPU 안에서 복사하고, load()는 거꾸로 복사한다(main.js:454–459). curl, 발산, MacCormack 중간 결과, 빛·블룸은 매번 다시 계산하는 임시값이라 상태에 넣지 않는다. 웜스타트 때문에 압력은 반드시 상태에 넣어야 한다. 빠뜨리면 점프백 검사에서 어긋난다.
  • 루프 끝 → 0이면 체크포인트 0(모두 0인 물)을 복원한다. 실시간 재생에서 프레임이 건너뛰면 그만큼 스텝을 더 돈다.
  • 헤드리스(?render)에서만 스텝마다 1픽셀 readPixels로 GPU 완료를 기다린다(main.js:449). 스크린샷 30초 타임아웃을 피하기 위한 하네스 우회다. 라이브 재생에서는 실행하지 않는다.
  • 결과: deterministic: true(앞→뒤, 새 페이지 뒤→앞, 점프백).
한계와 조절할 점
  • 2D 유체라서 3D 잉크의 볼륨감(소용돌이 고리가 뒤집히며 생기는 깊이)은 셰이딩으로 흉내만 낸다. 빛 레이마칭도 2D 평면 안의 근사다.
  • 야코비 30회는 완전 수렴이 아니라서 작은 압축성 잔차가 남는다. 멀티그리드나 레드-블랙 가우스-자이델을 쓰면 같은 비용에 더 정확하다.
  • 270×480 속도 격자의 해상도 한계 때문에 와도 감금으로 잔소용돌이를 보충한다. 너무 세면 콜리플라워 질감이 되어서 ε=7로 낮췄다.
  • 속도장도 MacCormack으로 이류하고 격자를 키우면 실제 GPU에서 더 가는 난류를 얻을 수 있다. 노즐을 글자 모양 경로로 움직이는 연출도 다음 후보다.
