데모는 영상 파일이 아니라 코드가 지금 그리는 화면이에요. 그래픽 카드를 많이 쓰는 기법이라 미리보기가 버벅일 수 있어요. 해상도를 낮춰 확인하고, MP4 렌더링은 시간이 더 걸려요. 재생 중 스페이스 · 클릭은 멈춤, ← →는 0.5초 이동이에요.

#025 · 아날로그 표현

목탄 스케치

WebGL2 · 종이 결에 걸리는 목탄 + 문지름·지우개

질감·필터무거움 · 그래픽 카드 사용
광고 · 쇼츠에서는목탄 스케치가 그려지는 제품 디자인 소개

활용 가이드

질감·필터로 쓸 때

화면 전체의 질감·색감을 바꿔 브랜드 무드를 만들 때 써요(필름, 판화, 수채화 등).

  • 질감은 영상 전체에 일관되게. 한 컷만 바꾸면 실수처럼 보여요.
  • 실사 영상 위에 필터로 얹고 싶다면 '이 영상 파일 위에 효과를 입혀'라고 요청해요.
  • 강도를 숫자로 조절할 수 있게 해 달라고 하면 수정이 쉬워요.

영상에 옮길 때 주의

  • 손으로 쓴 WebGL2 셰이더 — 영상 스킬의 WebGL 층(three.js 등) 위에서 다시 쓴다

만드는 법

  1. 준비하기

    Claude Code를 열고 빈 폴더에서 시작해요. aimotion 스킬을 처음 한 번 설치해요.

    claude plugin marketplace add kstost/cokacmotion claude plugin install aimotion@aimotion

  2. 프롬프트 만들기

    칸을 채우면 아래 프롬프트가 바로 바뀌어요. 데모의 장면이 아니라 내 장면을 적는 게 핵심이에요.

  3. 미리보기 보고 고치기

    Claude Code가 만든 HTML을 브라우저로 열어 확인하고, 고칠 점을 말로 알려 줘요. 자주 쓰는 수정 문장을 눌러 복사하세요.

  4. MP4로 뽑기

    실시간 화면 녹화보다 프레임 단위 렌더링이 끊김 없고 선명해요.

    이제 render(t)로 1/30초마다 프레임을 캡처해서 30fps MP4로 렌더링해 줘. 결과 파일 이름은 out.mp4로.

  5. 내 영상에 합치기

    제목 · 자막 · 전환처럼 실사 위에 얹을 효과라면 배경을 투명하게 뽑아 편집 프로그램(캡컷 · 프리미어)의 위 트랙에 올려요. 이미 찍은 영상이 있으면 파일을 주고 "이 영상 위에 효과를 입혀 줘"라고 해도 돼요.

    배경을 투명하게 해서 알파 채널이 있는 영상(ProRes 4444 .mov 또는 WebM)으로도 뽑아 줘.

초 단위로 보기

데모가 몇 초에 무엇을 보여 주는지예요. 장면을 따라 하려는 게 아니라, 기법이 어떤 순서와 리듬으로 쓰였는지 보는 용도예요.

제도판에 붙은 앵그르지 한 장(가로 줄무늬 결이 보이는 크림색 종이, 왼쪽 위에서 비스듬히 비추는 조명), 10초. 손에 든 도구(목탄 막대 · 옆으로 눕힌 목탄 토막 · 찰필 · 티슈 뭉치 · 떡지우개)가 종이 위에서 그림자를 끌며 움직인다(타임랩스).

  1. 0.35–1.9초 구도선: 탁자 선, 배와 찻잔의 중심축, 겹쳐 돌아가는 타원들 — 가볍고 빨라서 종이 결의 봉우리에만 걸린 끊긴 선.
  2. 1.9–3.2초 윤곽: 배·찻잔·받침·손잡이·천 주름. 그늘 쪽은 눌러서 진하게, 빛 쪽은 들어 올리며 흐리게.
  3. 3.2–5.2초 해칭: 배의 그늘(초승달 + 교차 해칭의 코어 섀도), 찻잔 안쪽과 몸통, 받침 두께, 드리운 그림자, 천 주름, 탁자 면.
  4. 5.2–6.5초 덩어리 톤: 막대를 옆으로 눕혀 벽을 지그재그로 두 번(오른쪽일수록 진하게), 탁자 앞면, 그림자 중심.
  5. 6.5–8.1초 문지름(절정): 티슈로 벽을 쓸어 거친 결이 부드러운 톤이 되고, 찰필로 배의 형태를 따라, 그림자와 찻잔 몸통, 주름을 문지른다.
  6. 8.1–9.1초 떡지우개: 벽 왼쪽에 빛 번짐을 들어내고, 배 하이라이트를 눌러 찍고, 찻잔 입술·받침 테·손잡이·탁자 모서리·주름 등성이에 가는 빛 선을 긋는다.
  7. 9.1–9.55초 마지막 강조: 물체가 닿는 곳의 가장 어두운 선. 이후 도구가 빠지고 카메라가 천천히 다가간다.

원리

개발자용 구현 설명이에요(원작자 노트, MIT). 몰라도 만들 수 있지만, Claude에게 "이 원리 중 ○○만 써 줘"처럼 지시할 때 도움이 돼요.

기법과 원리
  • 종이 이(tooth) 높이장 (HEIGHT, main.js:41): 워리 셀(펠트 같은 8 px 알갱이) + 레이드 라인(4.6 px 주기 가로 능선) + 체인 라인 (112 px 세로) + 섬유 잡음. 1080×1920 R8 텍스처로 setup에서 한 번 굽는다.
  • 목탄 침착 (STROKE_FS, main.js:63): 획은 리본(선분당 6정점, 정점마다 측면 −1..1·호 길이·필압·반폭·시드·종류, main.js:481). 프래그먼트에서 유효 필압 pe = 필압 × 단면 프로파일 × 막대 결(streak) 줄무늬로 정하고, 종이 높이 > 1 − pe 인 곳에만 침착 (main.js:78). 가벼운 획은 봉우리만 묻어 끊기고 거칠고, 같은 필압으로 여러 번 겹쳐도 봉우리만 진해지며, 세게 눌러야 골까지 찬다. 블렌딩 ONE, ONE_MINUS_SRC_ALPHA로 d ← d + (1 − d)·a (포화). 획 끝의 압력 곡선(flick / lift / swell, main.js:256), 손 떨림(main.js:264), 눌린 부스러기 점까지.
  • 옆으로 눕힌 막대(덩어리 톤): 같은 셰이더의 kind=1 — 폭 40–52 px의 평평한 단면, 끝이 부서진 가장자리, 진행 방향의 긴 줄무늬. 영역을 회전한 주사선으로 잘라 지그재그 한 획으로 잇는다(mass, main.js:422). 해칭은 같은 주사선 클리핑(다각형 − 제외 다각형, hatchRows, main.js:235)으로 그늘 모양 안에만 긋는다(hatch, main.js:393).
  • 찰필·티슈 문지름 (SMUDGE, main.js:86): 발자국(노이즈로 일그러진 원) 안에서 현재 값을 진행 반대쪽 상류(0.7 × 이동 거리)의 5탭 흐림 값과 섞는다(main.js:96) → 목탄이 끌려가고(이류) 퍼지며(블러) 골까지 메워진다. 한 번 지날 때마다 1.5%는 도구에 묻어 사라진다.
  • 떡지우개 (ERASE, main.js:104): d ← d · (1 − 발자국 · lift(높이)), lift는 봉우리 1.0 · 골 0.35(main.js:113) → 지운 자리의 골에 목탄이 남는다. 눌러 찍기(dab)는 제자리에서 여러 번, 끌기는 반경의 0.3배 간격으로.
  • 표시 (DISPLAY, main.js:118): 높이장 기울기로 종이 요철 음영(main.js:141), 진하게 눌린 목탄의 약한 광택, 조명 웅덩이, 시트 가장자리와 제도판.
  • 도구: 2D 오버레이 캔버스. 스프라이트는 setup에서 굽고(main.js:532), 시각 t의 위치·들림·도구 종류는 스크립트에서 바로 계산(toolPose, main.js:606). 막대 그림자는 닿은 점을 축으로 살짝 벌어져 막대가 종이에서 들려 있음을 보인다.
프레임마다 같은 그림이 나오게 하는 법 (결정성)
  • 모든 획·문지름·지우개는 setup의 buildScript(main.js:357)에서 rand(7) 하나로 만들어지고, 단계마다 출생 시각과 길이 비례 지속 시간을 받는다(schedule, main.js:295).
  • 침착은 누적이고 문지름은 순서에 의존하므로 replay(main.js:759): 1/30초 고정 단계, 단계 n은 [n·dt, (n+1)·dt)에 태어난 리본 조각을 그리고(main.js:706) 그 구간의 찰필/지우개 패스를 적용한다(main.js:738). 패스는 시저 사각형 안에서 B에 그린 뒤 같은 사각형만 A로 blit한다(main.js:719). 30단계마다 GPU 텍스처 복사로 체크포인트, 뒤로 가면 가장 가까운 체크포인트에서 다시 진행한다.
  • 침착 버퍼는 EXT_color_buffer_float가 있으면 R16F(반복 평균에도 계조가 무너지지 않음), 없으면 R8.
  • 도구 오버레이는 스크립트에서 t로 바로 계산하는 순수 함수다. 오버레이 2D 캔버스는 api.headless일 때만 willReadFrequently.
한계와 조절할 점
  • 해칭 구간에는 초당 수백 획이 나와(타임랩스) 도구가 프레임마다 여러 곳으로 뛴다. 실제 속도로 보여 주려면 구간을 늘리거나 해칭 밀도를 줄여야 한다.
  • 문지름은 목탄을 옮기기만 하고, 문지른 자리의 종이 결이 눌려 납작해지는 효과(높이장 변화)는 없다. 높이장을 상태로 두면 다음 획이 문지른 자리에 다르게 걸린다.
  • 침착은 단일 채널이다. 목탄 가루가 종이 위에 '얹힌' 양과 결에 '박힌' 양을 나누면 지우개가 앞의 것만 쉽게 들어내는 차이를 표현할 수 있다.
  • 형태(배·찻잔 그늘 영역)는 손으로 잡은 다각형이다. 간단한 3D 형상의 조명으로 톤 지도를 만들면 해칭 방향·압력을 형태에서 자동으로 얻을 수 있다.
