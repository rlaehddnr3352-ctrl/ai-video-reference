#017 · 웹 그래픽 기법

글자가 된 별

WebGL2 포인트 스프라이트 · 텍스트 샘플링

제목·로고무거움 · 그래픽 카드 사용
광고 · 쇼츠에서는흩어진 입자가 모여 브랜드명이 되는 오프닝

활용 가이드

제목·로고로 쓸 때

영상 첫 1–2초, 브랜드명이나 핵심 제목이 처음 나오는 순간에 써요.

  • 제목은 한 줄, 6–10자 안쪽이 가장 잘 보여요.
  • 기법이 끝난 뒤 0.5–1초는 글자를 멈춰 읽을 시간을 주세요.
  • 로고라면 브랜드 색 2–3개만 지정하면 나머지 톤은 AI가 맞춰요.

사전 카드와 함께 쓰기

G14 파티클 집합 카드와 같은 기법이에요. 카드의 예시 영상과 주문서 기능을 같이 써 보세요.

영상에 옮길 때 주의

  • 손으로 쓴 WebGL2 셰이더 — 영상 스킬의 WebGL 층(three.js 등) 위에서 다시 쓴다

만드는 법

  1. 준비하기

    Claude Code를 열고 빈 폴더에서 시작해요. aimotion 스킬을 처음 한 번 설치해요.

    claude plugin marketplace add kstost/cokacmotion claude plugin install aimotion@aimotion

  2. 프롬프트 만들기

    칸을 채우면 아래 프롬프트가 바로 바뀌어요. 데모의 장면이 아니라 내 장면을 적는 게 핵심이에요.

  3. 미리보기 보고 고치기

    Claude Code가 만든 HTML을 브라우저로 열어 확인하고, 고칠 점을 말로 알려 줘요. 자주 쓰는 수정 문장을 눌러 복사하세요.

  4. MP4로 뽑기

    실시간 화면 녹화보다 프레임 단위 렌더링이 끊김 없고 선명해요.

    이제 render(t)로 1/30초마다 프레임을 캡처해서 30fps MP4로 렌더링해 줘. 결과 파일 이름은 out.mp4로.

  5. 내 영상에 합치기

    제목 · 자막 · 전환처럼 실사 위에 얹을 효과라면 배경을 투명하게 뽑아 편집 프로그램(캡컷 · 프리미어)의 위 트랙에 올려요. 이미 찍은 영상이 있으면 파일을 주고 "이 영상 위에 효과를 입혀 줘"라고 해도 돼요.

    배경을 투명하게 해서 알파 채널이 있는 영상(ProRes 4444 .mov 또는 WebM)으로도 뽑아 줘.

초 단위로 보기

데모가 몇 초에 무엇을 보여 주는지예요. 장면을 따라 하려는 게 아니라, 기법이 어떤 순서와 리듬으로 쓰였는지 보는 용도예요.

어둠 속에서 은청색 나선은하가 떠오른다. 팔이 둘이고, 안쪽이 바깥보다 빨리 도는 차등 회전을 한다. 1.2 s부터 별들이 안쪽부터 차례로 은하를 떠나 소용돌이치며 모인다. 별 하나하나가 짧은 빛 꼬리를 끌고, 화면 가운데에 Pretendard 굵은 글씨 「별」이 선다. 글자 위로 빛줄기가 대각선으로 천천히 쓸고 지나간다. 몇 개의 별은 십자 회절광을 반짝이고, 배경 하늘은 어두워져 글자를 받쳐 준다. 5 s에 글자가 통째로 한 바퀴 휘감기며 원반 모양 소용돌이로 풀린다. 이 소용돌이가 왼쪽에서 오른쪽 순서로 다시 감기면서 금빛 「빛」이 된다(절정, 7.3 s 블룸 플래시). 8 s부터 「빛」이 장미빛·금빛 성진(stardust)으로 흩어진다. 성진은 반짝이며 바깥으로 소용돌이쳐 다시 금빛 나선은하가 된다. 별 → 글자 → 빛 → 다시 별로 돌아오는 고리다.

깊이는 네 겹으로 표현했다. 가장 뒤에 아주 옅은 보라·청록 fBm 성운과 글자 뒤의 넓은 색광이 있다. 그 앞에 깊이 z에 따라 크기와 밝기가 다른 별 11000개, 다시 그 앞에 글자 입자 37000개가 있다. 맨 앞에는 초점이 나간 큰 보케 13개가 시차 3배로 떠다닌다.

원리

개발자용 구현 설명이에요(원작자 노트, MIT). 몰라도 만들 수 있지만, Claude에게 "이 원리 중 ○○만 써 줘"처럼 지시할 때 도움이 돼요.

기법과 원리
  • 텍스트 샘플링(main.js:235 sampleGlyph). await document.fonts.load('860 700px "Pretendard Variable"', '별빛')(main.js:278) 뒤에 오프스크린 2D 캔버스에 글자를 그린다. measureText의 실제 경계 상자로 중심을 맞추고, 알파가 128 이상인 픽셀(내부)과 3px 안에 바깥이 있는 픽셀(윤곽)을 모은다. 점의 30%를 윤곽에서 뽑아(main.js:256) 입자로 채운 글자도 테두리가 또렷하게 읽힌다. 두 글자 모두 N개씩 뽑는다.
  • 대응 짓기(main.js:287–293). 「별」의 i번째 점은 중심 C 기준 각도 순위가 같은 「빛」의 점으로 간다. 그래서 모핑이 무작위 교환이 아니라 하나의 일관된 소용돌이가 된다.
  • 위치 = t의 닫힌 함수(정점 셰이더, main.js:19–92). 입자마다 속성 vec4 4개를 둔다. 은하 반지름·각·깊이·위상, 두 글자의 목표점, 지연 3개와 종류, 난수와 크기다.
  • galaxy(t)(main.js:33): 차등 회전 ω = 0.035 + 0.30/(1 + r/230).
  • spiral(A, B, e, bulge, turns)(main.js:40): C 기준 극좌표에서 반지름과 각을 보간한다. 은하 방향으로만 돌게 하거나, 최단 각에 정수 바퀴를 더한다(main.js:43). sin(πe)만큼 바깥으로 부풀린다.
  • 단계 진행도는 e1(모이기)·e2(모핑)·e3(흩어짐)이다(main.js:60–62). 입자별 지연은 은하 안쪽부터, 글자 왼쪽부터 오도록 정했다(main.js:311–313). 지연의 최댓값을 다음 단계 시작보다 작게 잡았다. 그래서 단계가 바뀌는 순간 위치가 정확히 이어진다(main.js:65–67).
  • 정지 구간의 반짝임은 위치 ±1.4px 흔들림과 밝기 sin으로 낸다. 쓸고 지나가는 빛은 목표점을 사선 방향으로 투영한 값의 sin^10이다(main.js:73). 성진의 번쩍임은 glint(main.js:79), 회절광 별 160개는 kind 2(main.js:82)다.
  • 소프트 원형 스프라이트(main.js:101–106). gl_PointCoord로 가우시안 코어와 헤일로를 만들고, 회절광 별은 축 방향 지수 스파이크를 더한다. blendFunc(ONE, ONE) 가산 합성이다(main.js:374).
  • 닫힌 형태의 셔터 → 빛 꼬리(main.js:381). 같은 버퍼를 t, t−0.023, t−0.046, t−0.069에서 네 번 그리고 각각 1/4 세기로 더한다. 멈춘 입자는 한 점이 되고, 날아가는 입자만 꼬리가 생긴다. 상태 없이 얻는 모션 블러다.
  • HDR 블룸. EXT_color_buffer_float가 있으면(main.js:281, SwiftShader에서 사용 가능) RGBA16F에 모은다. 1/4 해상도(4탭 박스 다운샘플 → 13탭 분리 가우시안)와 1/8 해상도 두 단계로 블룸을 만들고(main.js:393–398), 최종 패스에서 fBm 성운(main.js:184–185)과 합친다. 1 − exp(−c) 톤매핑(main.js:194), 비네트, 프레임 번호로 정하는 그레인(main.js:196)을 적용한다. 8비트 대체 경로에서는 세기를 절반으로 줄인다(main.js:354).
  • 연출 트랙(main.js:265–270): 줌, 페이드, 하늘 밝기, 글자 뒤 색광(은청 → 금), 「별」·「빛」 완성 시점의 블룸 플래시.
프레임마다 같은 그림이 나오게 하는 법 (결정성)
  • 상태가 없다. 모든 입자 위치·색·크기는 uniform t와 정적 속성만으로 정점 셰이더에서 계산한다. 이전 프레임의 버퍼를 읽지 않는다(매 프레임 FBO를 clear한다).
  • 텍스트 샘플링, 대응, 난수는 setup에서 rand(seed)로 한 번만 한다. 폰트 로드를 기다린 뒤 document.fonts.check로 확인한다.
  • 그리는 순서가 고정이라 가산 합성 결과도 같다. 그레인은 round(t·30)로 정한다. 렌더러 검사(정순·역순 새 페이지·되돌아가기): pass.
한계와 조절할 점
  • 글자 내부는 균일 샘플이라 가까이 보면 '반짝이는 모래'처럼 보인다. 거리장(SDF) 기반 밀도, 예컨대 획 중심선에 몰아 주기를 쓰거나 획 방향을 따른 흐름을 주면 더 서예적인 질감이 될 것이다.
  • 극좌표 보간은 중심 C 근처에서 각속도가 커진다. 「빛」의 'ㅣ' 같은 중심 근처 획은 모핑 중에 빠르게 돈다. C를 글자마다 다르게 두거나 경로를 베지어로 바꾸면 고를 수 있다.
  • 셔터 샘플이 4개라 아주 빠른 입자의 꼬리는 점선처럼 끊긴다. 속도에 따라 점을 늘이는 방식(정점 셰이더에서 속도를 미분해 쿼드로 그리기)이 더 싸고 매끄럽다.
  • 한글 두 글자 고정이다. sampleGlyph는 임의 문자열을 받을 수 있으니 단어나 문장 단위 시퀀스로 늘리기 쉽다.
  • 하네스 관련: setup 예외가 300 s 시간 제한 뒤에야 보고되는 문제는 03과 같다. 수정하지 않고 timeout으로 감싸 우회했다.
