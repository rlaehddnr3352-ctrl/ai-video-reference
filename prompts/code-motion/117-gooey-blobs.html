활용 가이드

제목·로고로 쓸 때

영상 첫 1–2초, 브랜드명이나 핵심 제목이 처음 나오는 순간에 써요.

  • 제목은 한 줄, 6–10자 안쪽이 가장 잘 보여요.
  • 기법이 끝난 뒤 0.5–1초는 글자를 멈춰 읽을 시간을 주세요.
  • 로고라면 브랜드 색 2–3개만 지정하면 나머지 톤은 AI가 맞춰요.

배경·분위기로 쓸 때

글자나 제품 뒤에 깔리는 배경, 분위기를 잡는 오프닝·엔딩에 써요.

  • 배경은 주인공보다 어둡거나 덜 선명하게. 대비가 강하면 글자가 안 읽혀요.
  • 루프로 만들어 두면 여러 영상에 재사용할 수 있어요.
  • 무거운 셰이더 배경은 미리 렌더링해 영상 파일로 깔면 편해요.

만드는 법

  1. 준비하기

    Claude Code를 열고 빈 폴더에서 시작해요. aimotion 스킬을 처음 한 번 설치해요.

    claude plugin marketplace add kstost/cokacmotion claude plugin install aimotion@aimotion

  2. 프롬프트 만들기

    칸을 채우면 아래 프롬프트가 바로 바뀌어요. 데모의 장면이 아니라 내 장면을 적는 게 핵심이에요.

  3. 미리보기 보고 고치기

    Claude Code가 만든 HTML을 브라우저로 열어 확인하고, 고칠 점을 말로 알려 줘요. 자주 쓰는 수정 문장을 눌러 복사하세요.

  4. MP4로 뽑기

    실시간 화면 녹화보다 프레임 단위 렌더링이 끊김 없고 선명해요.

    이제 render(t)로 1/30초마다 프레임을 캡처해서 30fps MP4로 렌더링해 줘. 결과 파일 이름은 out.mp4로.

  5. 내 영상에 합치기

    제목 · 자막 · 전환처럼 실사 위에 얹을 효과라면 배경을 투명하게 뽑아 편집 프로그램(캡컷 · 프리미어)의 위 트랙에 올려요. 이미 찍은 영상이 있으면 파일을 주고 "이 영상 위에 효과를 입혀 줘"라고 해도 돼요.

    배경을 투명하게 해서 알파 채널이 있는 영상(ProRes 4444 .mov 또는 WebM)으로도 뽑아 줘.

초 단위로 보기

데모가 몇 초에 무엇을 보여 주는지예요. 장면을 따라 하려는 게 아니라, 기법이 어떤 순서와 리듬으로 쓰였는지 보는 용도예요.

미감은 굵은 평면 팔레트와 그레인이다. 장면 A는 크림 종이(#f4ecdd)에 먹색 글자를 쓰고, 액체는 해바라기(#ffc21e)·토마토(#ff5433)를 쓴다. 장면 B는 코발트(#293ece)에 해바라기 제목을 얹는다. 강조색은 장면마다 하나다(A 토마토, B 해바라기). 위 막대(「몽글 연구소」, 01 / 04 장 번호)와 아래 막대(01 SPLIT 같은 장 이름, 진행 표시 네 칸)는 방송 그래픽처럼 끝까지 자리를 지킨다.

1.62 목이 끊어진다(똑). 두 반쪽은 각자 몸으로 튕겨 들어가고, 가운데에 작은 위성 방울이 남았다가 새 방울에 삼켜진다. 떨어진 방울은 늘었다 줄었다 출렁이고, 「똑」(토마토, 132px)이 튀어나온다.
2.2–3.3 02 MERGE 「다시 붙고」. 두 방울이 벌어졌다가 끝이 동그란 팔을 서로 뻗는다. 팔끝이 닿을 듯 말 듯 떤다.
3.36 팔끝이 붙는 순간 다리가 단숨에 굵어지고, 두 몸이 outBack으로 당겨져 땅콩 모양 하나가 된다. 허리는 노랑→주황→토마토로 섞인다. 주황 물방울 일곱 개가 튀고, 링과 콜아웃 「닿는 순간, 하나」가 나온다.
3.9–4.85 03 WRAP 「감싸 안고」. 덩어리가 줄기처럼 늘어나 제목까지 기어오른다. 글자를 감싸되, 글자 둘레에는 틈을 남기고 흐른다.
4.86–5.3 토마토색 액체가 먹색 글자 속으로 스며든다. 이어 글자가 장에 합류해 부풀고 아래로 처지며 둘레의 액체와 이어진다. 이음매에서 색이 섞인다(절정 1).
5.3–5.98 액체가 아래로 놓아준다. 글자에 매달린 목이 늘어나 끊어지고, 글자는 다시 또렷해진다. 마지막에는 토마토색 활자 「감싸 안고」로 바뀌어 남는다.
5.9–6.5 와이프 떨어진 액체가 바닥에서 출렁이는 원반으로 부풀어 화면을 덮는다. 테두리는 울퉁불퉁하고 광택이 있다.
6.5–7.6 04 FLOW 노랑이 덮은 아래에서 장면이 코발트로 바뀐다. 액체가 구멍을 내며 빠지고, 제목 「몽글 / 몽글」(300px)이 노란 액체 안에서 돋을새김처럼 떠오른다. 남은 액체는 글자로 응축된다(절정 2, 포스터 7.0 s).
7.66 제목이 또렷한 활자로 바뀐다. 구운 광택 띠가 있고, 액체 그림자는 그대로 남는다. 토마토·우유·분홍 방울이 톡 나타난다.
7.8–8.6 태그라인 「떨어져도, 다시 하나」와 부제 「붙고, 갈라지고, 감싸는 액체의 모양」이 들어온다.
8.2–9.5 둘째 줄 「글」 밑에서 방울이 맺힌다. 목이 가늘어져 끊어지고(1장의 메아리), 방울이 떨어져 바닥 줄 위에 납작하게 앉는다. 토마토 방울은 첫 「글」에 살짝 붙었다가 떨어진다.

글꼴(모두 FONTS 등록, OFL 1.1): 한글은 Pretendard Variable(900/800/700/500), 라틴과 숫자 라벨은 Bricolage Grotesque Variable(700)이다. 장 번호 숫자는 고정 칸에 한 자씩 그려 고정폭으로 맞췄다.

기법과 원리

왜 SVG gooey 필터가 아니라 축소 해상도 장 + smoothstep인가

블러 + 알파 대비 행렬(SVG gooey)은 01번이 이미 썼다. 이 방식은 결과가 알파 마스크 하나뿐이다. 여기서는 세 가지가 더 필요해서 장(field)을 직접 계산했다. - 장의 기울기가 필요하다. 테두리 광택(법선 방향으로 안쪽에 들어앉은 하이라이트)과 안쪽 그라데이션을 만든다. - 조각마다 색이 있어야 한다. 그래야 붙는 곳에서 색이 섞인다. - 글자 커버리지를 더하고 빼야 한다. 빼면 액체가 글자를 비켜 흐르고, 더하면 글자가 녹아 합류한다.

장은 540×960칸(무대의 ½)에서 계산하고, 캔버스를 CSS로 2배 키워 합성한다. 프레임당 JS는 헤드리스에서 30–45 ms다.

장 (goo.js)

  • 커널(goo.js:23 ball, goo.js:48 capsule)
  • Wyvill 커널 k = (1 − d²/S²)³을 쓴다. 받침이 유한해서 공마다 자기 상자 안만 돈다.
  • 등가면은 T = 0.3이고, 보이는 반지름 r에 대해 S = r / √(1 − T^⅓) ≈ 1.74 r이다. 그래서 반지름은 무대 px로 바로 지정한다.
  • 같은 크기 공 둘은 중심 거리 2.38 r(표면 틈 0.38 r)에서 다리가 생긴다. 이것이 "닿기 직전에 끌려가 붙는" 느낌의 정체다.
  • 공은 회전 타원도 된다(찌그러짐·늘어남). 캡슐은 선분까지의 거리를 쓰고, 색이 한 끝에서 다른 끝으로 흐른다.
  • 색 섞기: 조각마다 Σk²·c / Σk²로 더한다. k 대신 k²로 가중하면 각 몸의 색은 지키고 이음매에서만 섞인다.
  • 글자를 장에 넣기(goo.js:108 textField)
  • 무대 해상도로 글자를 래스터한 뒤 2×2 평균으로 칸 커버리지를 만든다.
  • 잉크 상자 + 여백으로 잘라 흐림 단계 다섯 개(σ ≈ 0, 1.4, 3.5, 6.5, 11칸)를 굽는다.
  • 화면의 활자와 같은 글리프 배치(main.js:192 layout)를 쓰므로 둘이 겹친다.
  • 비켜 흐르기(goo.js:148 carve): 가장 흐린 커버리지로 기존 장을 곱해 깎는다(F *= 1 − amt·smooth(c)). 더하기가 아니라 곱하기라서 액체가 아무리 두꺼워도 글자 둘레에 틈이 생긴다.
  • 녹아 합류하기(goo.js:167 text)
  • F += 2T·gain·c를 더한다. 또렷한 글자의 등가선이 정확히 커버리지 50 % 가장자리에 놓인다.
  • 녹임 값 m(0–3)은 흐림 단계를 오르며 보간한다. 글자가 부풀고, 모서리가 둥글어지고, 옆의 액체와 이어진다.
  • 흐릴수록 봉우리가 낮아지므로 이득을 1 + 0.42m로 보상한다.
  • slump는 열마다 다른 양(부드러운 값 노이즈 cn)만큼 글자 아래쪽을 끌어내린다. 그래서 글자가 처지고 흘러내린다.
  • 와이프(goo.js:198 wipe)
  • 착지한 자리 WC를 중심으로 한 원반이고, 장은 선형 경사 2T·(½ + (R + wob − r)/w)를 상한에서 자른 값이다.
  • 테두리 흔들림 wob는 각도에 대한 사인 세 개(5·9·14배)다. 각도는 setup에서 표로 구웠다(angleField).
  • 장이 선형이라 거리 추정이 정확하다. 그래서 테두리 광택이 깨끗하고, 원반에 닿는 방울과도 자연스럽게 이어진다.
  • 빠지기(goo.js:226 drain)
  • 화면을 채운 항 2T·clamp(2.4s + 0.15 + lift − 0.7·DN − 1.3·NZ, 0, 1.4)이다.
  • DN은 제목 잉크 상자로부터의 거리, NZ는 3옥타브 값 노이즈다(main.js:400-419).
  • s가 줄면 구멍은 노이즈가 높고 제목에서 먼 곳부터 열린다. 남은 액체는 제목 글자 장으로 모인다.
  • lift가 처음 0.12초 동안 장을 포화시켜, 와이프의 평평한 바닥에서 이음매 없이 이어받는다.

셰이딩 (goo.js:249 shade)

  • 가장자리: 거리 추정 d = (F − T)/|∇F|(칸, 안쪽이 +)로 alpha = clamp(d + ½)를 정한다(goo.js:263-264). 장의 모양이 무엇이든 가장자리가 한 칸 폭으로 안티에일리어싱된다. 컴포지터의 2배 쌍선형 확대를 거치면 무대에서 약 2 px가 된다.
  • 베개 법선: 테두리에서 가파르고(기울기 1.7·(1 − d/22)²) 안쪽은 평평하다. 깊이는 거리 추정과 장 값 (F − T)/1.8T 중 큰 쪽을 쓴다(goo.js:276). 장 안에 묻힌 작은 조각이 만드는 가파른 국소 기울기가 주름으로 보이지 않게 하려는 것이다.
  • 안쪽 그라데이션: 왼쪽 위 빛의 램버트 항, 중심부를 살짝 밝히는 장 값 항, 화면 세로 그라데이션을 곱한다(goo.js:282).
  • 광택 테두리: 하프 벡터와의 정반사 값을 smoothstep(0.935, 0.965)로 잘라 또렷한 초승달을 만든다(goo.js:284). 정반사가 최대인 곳은 베개 기울기가 0.48인 깊이(테두리 안쪽 약 10칸 = 20 px)다. 그래서 하이라이트가 법선을 따라 안쪽으로 들어앉은 띠가 된다. 붙고 갈라질 때마다 모양을 그대로 따라간다.
  • 그림자: 오른쪽 아래로 (7, 11)칸 어긋난 장 표본에서 얻는다(goo.js:258). 크림 위에서는 갈색 20 %, 코발트 위에서는 남색 34 %다.

  • 상태가 없다. 모든 조각의 위치·반지름·색은 t의 닫힌 식이고, 매 프레임 장을 0에서 다시 쌓는다(goo.js:20 clear). late()의 출발 자세 START = early(4.3)도 setup에서 순수 함수로 한 번 계산한다.
  • 난수는 쓰지 않는다. 글자 열 노이즈, 값 노이즈, 그레인은 고정 시드의 정수 해시로 setup에서 굽는다.

한계와 조절할 점
  • 실시간 비용: 장 계산과 셰이딩이 JS 루프다(GPU가 아니라 CPU). 일반 브라우저에서 프레임당 약 25–40 ms로 30 ms 예산에 걸친다. 와이프·빠지기 구간(화면 전체 칸을 도는 항)이 가장 무겁다. 행 단위 조기 종료나 Web Worker로 더 줄일 수 있다.
  • 가장자리 해상도: 장이 ½ 해상도라 액체 가장자리는 무대에서 약 2 px로 부드럽다. 녹은 글자는 반 해상도 래스터라 가는 획이 조금 뭉툭하다. 그래서 "또렷한" 상태는 늘 활자로 바꿔 끼운다(5.86, 7.66초).
