#001 · 웹 그래픽 기법

먹 한 방울

SVG 필터 · feTurbulence + feDisplacementMap

제목·로고배경·분위기가벼움 · 브라우저 기능만
광고 · 쇼츠에서는전통 · 차 · 한식 브랜드 오프닝에서 로고나 제목을 먹처럼 번지며 등장시키기

활용 가이드

제목·로고로 쓸 때

영상 첫 1–2초, 브랜드명이나 핵심 제목이 처음 나오는 순간에 써요.

  • 제목은 한 줄, 6–10자 안쪽이 가장 잘 보여요.
  • 기법이 끝난 뒤 0.5–1초는 글자를 멈춰 읽을 시간을 주세요.
  • 로고라면 브랜드 색 2–3개만 지정하면 나머지 톤은 AI가 맞춰요.

배경·분위기로 쓸 때

글자나 제품 뒤에 깔리는 배경, 분위기를 잡는 오프닝·엔딩에 써요.

  • 배경은 주인공보다 어둡거나 덜 선명하게. 대비가 강하면 글자가 안 읽혀요.
  • 루프로 만들어 두면 여러 영상에 재사용할 수 있어요.
  • 무거운 셰이더 배경은 미리 렌더링해 영상 파일로 깔면 편해요.

만드는 법

  1. 준비하기

    Claude Code를 열고 빈 폴더에서 시작해요. aimotion 스킬을 처음 한 번 설치해요.

    claude plugin marketplace add kstost/cokacmotion claude plugin install aimotion@aimotion

  2. 프롬프트 만들기

    칸을 채우면 아래 프롬프트가 바로 바뀌어요. 데모의 장면이 아니라 내 장면을 적는 게 핵심이에요.

  3. 미리보기 보고 고치기

    Claude Code가 만든 HTML을 브라우저로 열어 확인하고, 고칠 점을 말로 알려 줘요. 자주 쓰는 수정 문장을 눌러 복사하세요.

  4. MP4로 뽑기

    실시간 화면 녹화보다 프레임 단위 렌더링이 끊김 없고 선명해요.

    이제 render(t)로 1/30초마다 프레임을 캡처해서 30fps MP4로 렌더링해 줘. 결과 파일 이름은 out.mp4로.

  5. 내 영상에 합치기

    제목 · 자막 · 전환처럼 실사 위에 얹을 효과라면 배경을 투명하게 뽑아 편집 프로그램(캡컷 · 프리미어)의 위 트랙에 올려요. 이미 찍은 영상이 있으면 파일을 주고 "이 영상 위에 효과를 입혀 줘"라고 해도 돼요.

    배경을 투명하게 해서 알파 채널이 있는 영상(ProRes 4444 .mov 또는 WebM)으로도 뽑아 줘.

초 단위로 보기

데모가 몇 초에 무엇을 보여 주는지예요. 장면을 따라 하려는 게 아니라, 기법이 어떤 순서와 리듬으로 쓰였는지 보는 용도예요.

한지(섬유결이 비치는 아이보리 종이, 아래쪽은 찢긴 가장자리 너머 검은 펠트) 위로 먹 한 방울이 카메라 쪽에서 떨어진다. 처음엔 초점이 나간 큰 구슬이었다가 종이에 가까워지며 작고 선명해지고, 그림자가 방울 쪽으로 모여든다(0.15–1.35 s). 닿는 순간 먹이 튀며 번지고(1.35 s), 그 먹물이 봉우리 꼭대기로 빨려 들어가듯 줄어드는 동안 주봉이 위에서부터 번져 나온다. 이어 먼 산(청회색 옅은 먹), 중경 능선(잔 나무 점), 강과 물결, 전경의 바위와 소나무가 차례로 스며 나오고(2–7 s), 봉우리 밑동에는 안개가 흐른다. 마지막으로 나룻배, 옅은 주홍 해와 하늘의 온기, 날아가는 새 세 마리, 오른쪽 아래 붉은 낙관 「먹」이 찍힌다(7.9 s). 끝 0.55 초 동안 먹이 종이 속으로 가라앉아, 처음(빈 종이)으로 이어진다. 깊이는 먹의 농담으로 만든다: 먼 산은 옅고 흐리게(반해상도), 주봉은 진하고 테두리가 살아 있게, 소나무는 가장 짙고 날카롭게.

원리

개발자용 구현 설명이에요(원작자 노트, MIT). 몰라도 만들 수 있지만, Claude에게 "이 원리 중 ○○만 써 줘"처럼 지시할 때 도움이 돼요.

기법과 원리
  • 먹 레이어 하나 = 필터 두 단계 (inkLayer, main.js:172).
  • setup — 번진 먹을 굽는다 (bake, main.js:188): 레이어의 도형(알파 = 먹의 농도)을 feTurbulence(고정 seed) → feDisplacementMap(섬유 방향으로 흐트러진 가장자리) → feGaussianBlur(번짐)에 통과시켜 두 번 래스터한다 — 젖은 먹(변위·블러 큼)과 마른 먹(가장자리가 자리 잡음). 값은 LAYERS의 d/s(main.js:216). 번짐이 도착하는 시간을 담은 지도도 굽는다: B 채널 = 번짐 시작점 중심의 방사형 그라디언트 + 노이즈.
  • frame — 싼 필터 하나: feImage(젖은 먹) ⊕ feImage(마른 먹)을 feComposite arithmetic으로 섞고(k = 젖은 정도, main.js:179), 지도의 B로 feColorMatrix alpha = slope·(B − thr)를 만들어(main.js:180) 가린다. thr를 1.08 → −0.25로 내리면 노이즈 때문에 손가락처럼 갈라지는 모세관 번짐 전선이 나아가고, feComponentTransfer table 0, 1, .84가 전선 띠에서만 알파를 1까지 올려 먹이 고이는 젖은 가장자리를 만든다. 젖은 먹은 전선이 지나간 뒤 마른 먹으로 스며든다.
  • 농담(水墨): wash(main.js:71)는 능선 아래로 같은 투명도의 띠 N장을 겹쳐 능선을 따라 짙고 아래로 옅어지는 그라디언트를 만든다(끝은 오므리고 바닥선 아래로는 내려가지 않는다). 그 위에 피마준 같은 붓 획(main.js:324), 끊긴 능선 윤곽, 태점, brush(main.js:86)로 만든 굵기 변하는 획(소나무 줄기·가지·솔잎 부채)을 얹는다.
  • 먹방울과 튐: 원 + 튀는 방울 14개에 고전적인 "gooey" 체인을 실시간으로 건다(main.js:454): 변위 → 블러 → 가파른 알파 임계 → 알파 − 블러(알파)로 마른 테두리 강조. 560×480 영역에 한정되고 1.35–3.65 s에만 돈다. 반지름이 펼쳐졌다가 0으로 줄어 "산이 먹을 마신다".
  • 떨어지는 먹방울: 광택 있는 구슬을 한 번만 그려 두고(main.js:508), 떨어짐은 CSS transform(위치·크기), 초점은 CSS filter: blur()(main.js:548), 그림자는 부드러운/선명한 타원 두 장의 교차 페이드(main.js:523) — 모두 컴포지터가 적용하는 속성이라 낙하 동안 다시 그리는 것이 없다.
  • 종이: feTurbulence(섬유, 5옥타브) → feDiffuseLighting(main.js:263)으로 결을 비추고, 다른 노이즈의 feDisplacementMap으로 아래 가장자리를 찢는다. 그 위에 긴 닥섬유 곡선과 왼쪽 위 빛·가장자리 그늘.
  • 안개: 종이색 타원을 길게 늘인 노이즈로 휘게 하고(main.js:355, 반해상도) mix-blend-mode: lighten으로 얹는다 — 맨 종이 위에선 보이지 않고 먹만 가린다. 타원이 고정된 변위장 속을 흘러가므로 윤곽이 계속 변한다.
  • 낙관: 막대로 짠 「먹」(ㅁ·ㅓ·ㄱ)을 붉은 판에서 오려낸 백문인. 작은 실시간 feTurbulence로 눌림 얼룩을 만들고(main.js:481), feColorMatrix 상수(압력)가 커지며 인주가 차오른다(main.js:605).
한계와 조절할 점
  • Chromium 이상 동작: 원소를 참조하는 feImage(href="#id")는 부분영역 원점만큼 원소를 다시 옮겨 그리고, 어떤 그룹에서는 필터 전체가 조용히 빠지는 일이 있었다(같은 필터를 복제해도). 모든 지도를 비트맵으로 구워 이 문제를 피했다.
  • 번짐은 "도착 시간장 + 임계값"의 근사다. 실제 먹의 확산(물의 양, 종이 흡수율, 겹친 붓질의 번짐 경계)은 아니다 — 반응-확산이나 격자 위 확산 시뮬레이션을 setup에서 구워 도착 시간장으로 쓰면 더 사실적인 갈래가 나온다.
  • 해는 단순한 원이고, 글씨(제화시)가 없다. 붓글씨 폰트나 획 데이터가 있으면 세로 제화와 낙관의 배치를 완성할 수 있다.
  • 젖음→마름은 두 장의 구운 먹 사이의 교차 페이드다. 변위 크기가 연속으로 줄어드는 원래 효과와 완전히 같지는 않다(중간 단계를 더 구우면 가까워진다).
  • 먼 산을 반해상도로 그린 것은 헤드리스 예산 때문이다. GPU 재생만 생각하면 전체 해상도로 되돌려도 된다(res: 0.5).
