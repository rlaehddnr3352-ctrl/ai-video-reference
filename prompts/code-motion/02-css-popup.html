#002 · 웹 그래픽 기법

펼쳐지는 종이 마을

CSS 3D 변형 · perspective + preserve-3d

제품·앱 소개3D·공간가벼움 · 브라우저 기능만
광고 · 쇼츠에서는매장 · 동네 소개를 팝업북처럼 펼쳐 보이는 오프닝

활용 가이드

제품·앱 소개로 쓸 때

제품·앱·서비스의 생김새나 기능을 보여 주는 장면에 써요.

  • 실제 제품 사진(배경 제거 PNG)이나 앱 화면 캡처를 함께 주면 그대로 넣어 움직여요.
  • 기능 하나당 2–3초, 한 화면에 한 가지만 보여 주세요.
  • 가격·혜택 같은 숫자는 코드로 넣어야 깨지지 않아요.

3D·공간로 쓸 때

제품이나 공간을 입체로 돌려 보거나 카메라가 공간을 지나가는 장면에 써요.

  • 제품 3D 모델(GLB)이 있으면 그대로 쓰고, 없으면 단순한 도형으로 만들어 달라고 해요.
  • 카메라 움직임은 한 방향으로 하나만. 사전의 카메라 무빙 카드 이름을 같이 쓰면 정확해요.
  • GPU를 많이 쓰니 렌더링은 시간이 걸려요. 해상도를 낮춰 미리 보고 마지막에 올리세요.

만드는 법

  1. 준비하기

    Claude Code를 열고 빈 폴더에서 시작해요. aimotion 스킬을 처음 한 번 설치해요.

    claude plugin marketplace add kstost/cokacmotion claude plugin install aimotion@aimotion

  2. 프롬프트 만들기

    칸을 채우면 아래 프롬프트가 바로 바뀌어요. 데모의 장면이 아니라 내 장면을 적는 게 핵심이에요.

  3. 미리보기 보고 고치기

    Claude Code가 만든 HTML을 브라우저로 열어 확인하고, 고칠 점을 말로 알려 줘요. 자주 쓰는 수정 문장을 눌러 복사하세요.

  4. MP4로 뽑기

    실시간 화면 녹화보다 프레임 단위 렌더링이 끊김 없고 선명해요.

    이제 render(t)로 1/30초마다 프레임을 캡처해서 30fps MP4로 렌더링해 줘. 결과 파일 이름은 out.mp4로.

  5. 내 영상에 합치기

    제목 · 자막 · 전환처럼 실사 위에 얹을 효과라면 배경을 투명하게 뽑아 편집 프로그램(캡컷 · 프리미어)의 위 트랙에 올려요. 이미 찍은 영상이 있으면 파일을 주고 "이 영상 위에 효과를 입혀 줘"라고 해도 돼요.

    배경을 투명하게 해서 알파 채널이 있는 영상(ProRes 4444 .mov 또는 WebM)으로도 뽑아 줘.

초 단위로 보기

데모가 몇 초에 무엇을 보여 주는지예요. 장면을 따라 하려는 게 아니라, 기법이 어떤 순서와 리듬으로 쓰였는지 보는 용도예요.

어두운 호두나무 책상 위에서 금박 테두리와 「종이 마을 · 펼쳐 보세요」 글씨가 찍힌 천 장정 팝업북이 어둠 속에서 떠오른다(0–0.45 s). 표지가 접힌 선(gutter)을 축으로 일어서며(0.45–2.7 s) 안쪽에 인쇄된 노을 하늘이 드러나고, 하늘과 나란히 종이 산맥 두 겹이 선다. 앞 페이지(풀밭, 강, 오솔길이 인쇄된 종이)에서는 집 다섯 채가 차례로 일어선다: 오각형 앞벽이 서고, V자로 접혀 있던 옆벽이 벌어지고, 기와 줄무늬 지붕 두 장이 뚜껑처럼 닫힌다(빵집·책방·꽃집 간판). 나무(둥근 나무와 층층 침엽수, 두 장이 십자로 엇갈림), 아치 돌다리와 난간, 가로등이 선다. 카메라는 높고 먼 시점에서 낮고 가까운 시점으로 천천히 들어간다. 4 s부터 종이 해가 홈을 따라 산 뒤로 내려가고 빛이 푸르스름하게 식으며, 6 s부터 책상 오른쪽 스탠드의 따뜻한 빛, 창문 불빛과 그 앞 바닥의 빛 번짐, 가로등 세 개, 달과 별이 하나씩 켜진다. 마지막 0.4 s에 다시 어둠으로 가라앉아 처음과 이어진다.

원리

개발자용 구현 설명이에요(원작자 노트, MIT). 몰라도 만들 수 있지만, Claude에게 "이 원리 중 ○○만 써 줘"처럼 지시할 때 도움이 돼요.

기법과 원리
  • 카메라 = perspective + 회전된 world (main.js:334–339): .cam의 perspective: 1700px/perspective-origin이 렌즈, .world의 translate3d(0, lift, dolly) rotateX(tilt)가 책상 기울기와 달리(dolly)다.
  • 접힘선에 놓인 transform-origin = 경첩 (hinge, main.js:71, Node, main.js:47). 노드는 모두 preserve-3d로 중첩된다.
  • 뒷장: origin = 아래 변(gutter), rotateX(−φ) 180° → 98°(main.js:327, 341). 안쪽 하늘과 바깥 표지는 서로 등을 댄 두 장이고 backface-visibility: hidden(style.css:10)이라 접혀 있을 땐 표지만, 펼치면 하늘만 보인다. 닫힌 책에서는 뒷장 전체가 뒤집혀 있으므로 표지 글씨는 180° 돌려 인쇄했다(main.js:166).
  • 평행 접기 산맥: 밑변 축 rotateX(−180° + a), a는 책이 펼쳐진 정도에서 나온다 — 덮으면 앞으로 납작하게, 펼치면 뒷장과 나란히 선다(main.js:353 부근).
  • 집: rotateZ(yaw) rotateX(−180° + 90°·rise)(main.js:362) 안에 옆벽 경첩 rotateY(176° → 90°)(main.js:364), 지붕 두 장은 박공의 두 빗변에 rotateZ(경사각) rotateX(−175° → −90°)로 달린 뚜껑(main.js:365).
  • 나무: 선 카드 안에 같은 모양의 카드를 rotateY(8° → 90°)로 돌려 십자 입체를 만든다(main.js:380).
  • 카드 = 인쇄된 종이 (card, main.js:96): 종이 결 텍스처(setup에서 그린 256 px 노이즈, main.js:81)를 그림 위에 multiply로 겹친다. 그림은 CSS 그라디언트이거나 setup에서 캔버스로 한 번 그린 PNG(앞 페이지의 풀밭·강·길·풀 터치 main.js:235, 하늘과 먼 산 main.js:257, 별). 모양은 clip-path: 오각형 앞벽(polygon), 아치 다리와 구름·나무(path), 해·달(circle), 산맥 실루엣(노이즈 섞은 polygon). 문·창·둥근 다락창·간판 글씨(Gaegu)는 카드 안의 DOM으로 인쇄된다. 카드의 인쇄는 setup 이후 절대 바뀌지 않는다 — 프레임마다 바뀌는 것은 transform, filter, opacity뿐이다.
  • 면마다의 조명 (main.js:401–411): 매 프레임 각 노드의 회전을 3×3 행렬로 합성해 R을 얻고(update, main.js:62) 카드의 법선 n = R·(0,0,1). 밝기 = 주변광 + 해·max(0, n·Ls) + 0.9·램프·max(0, n·Ll), 따뜻함 = 램프·max(0, n·Ll) (+ 해 질 녘의 해)를 카드의 filter: brightness() saturate() sepia()로 쓴다. 필터는 이미 래스터된 카드에 컴포지터가 적용하므로 조명이 바뀌어도 3D 레이어를 다시 그리지 않는다. 종이는 양면이므로 앞면·뒷면의 빛을 둘 다 계산해 카드가 모서리로 설 때(n·view ≈ 0) 부드럽게 섞는다.
  • 빛나는 것들: 창문 불빛(main.js:294), 가로등 전구, 바닥의 빛 번짐·그림자, 달·별은 조명을 받지 않는 카드이고 opacity만 바뀐다.
  • 책상(2D): 나뭇결·책 그림자·스탠드 빛 웅덩이·어둠을 배경 그라디언트로 매 프레임 다시 칠한다(main.js:416).
프레임마다 같은 그림이 나오게 하는 법 (결정성)
  • 모든 값은 t의 순수 함수(track/ramp/ease), 배치와 질감은 rand(seed). frame(t)는 이전 상태를 읽지 않는다 (put은 같은 값이면 다시 쓰지 않을 뿐, main.js:118).
  • 첫 프레임 전에 준비를 끝낸다: 인쇄에 쓰는 Gaegu 두 굵기(index.html에서 @font-face를 링크하고 쓸 글자로 document.fonts.load, main.js:133)와 모든 PNG 그림의 디코드(main.js:231).
한계와 조절할 점
  • 그림자는 진짜 그림자가 아니라 바닥에 깐 흐린 카드다. 빛 방향에 따라 그림자 카드를 기울여(투영 행렬) 늘이면 더 정확해진다.
  • 팝업 메커니즘은 연출이다(집은 시간으로 일어선다). 실제 V-접기처럼 페이지 각도에서 각 판의 각도를 구속식으로 풀면 책을 앞뒤로 흔들 때도 종이처럼 따라 움직인다.
  • CSS 필터로는 임의의 색을 곱할 수 없어 빛의 색은 밝기·채도·세피아(따뜻함)로 근사한다. 푸른 저녁빛을 정확히 넣으려면 장면 위에 multiply 그레이딩 레이어(2D)를 하나 두는 방법이 있다(창문 불빛도 함께 물드는 것이 단점).
