타일로 짠 글자

제목·로고무거움 · 그래픽 카드 사용
광고 · 쇼츠에서는타일 패턴으로 짜이는 제목

활용 가이드

제목·로고로 쓸 때

영상 첫 1–2초, 브랜드명이나 핵심 제목이 처음 나오는 순간에 써요.

  • 제목은 한 줄, 6–10자 안쪽이 가장 잘 보여요.
  • 기법이 끝난 뒤 0.5–1초는 글자를 멈춰 읽을 시간을 주세요.
  • 로고라면 브랜드 색 2–3개만 지정하면 나머지 톤은 AI가 맞춰요.

영상에 옮길 때 주의

  • 손으로 쓴 WebGL2 셰이더 — 영상 스킬의 WebGL 층(three.js 등) 위에서 다시 쓴다

만드는 법

  1. 준비하기

    Claude Code를 열고 빈 폴더에서 시작해요. aimotion 스킬을 처음 한 번 설치해요.

    claude plugin marketplace add kstost/cokacmotion claude plugin install aimotion@aimotion

  2. 프롬프트 만들기

    칸을 채우면 아래 프롬프트가 바로 바뀌어요. 데모의 장면이 아니라 내 장면을 적는 게 핵심이에요.

  3. 미리보기 보고 고치기

    Claude Code가 만든 HTML을 브라우저로 열어 확인하고, 고칠 점을 말로 알려 줘요. 자주 쓰는 수정 문장을 눌러 복사하세요.

  4. MP4로 뽑기

    실시간 화면 녹화보다 프레임 단위 렌더링이 끊김 없고 선명해요.

    이제 render(t)로 1/30초마다 프레임을 캡처해서 30fps MP4로 렌더링해 줘. 결과 파일 이름은 out.mp4로.

  5. 내 영상에 합치기

    제목 · 자막 · 전환처럼 실사 위에 얹을 효과라면 배경을 투명하게 뽑아 편집 프로그램(캡컷 · 프리미어)의 위 트랙에 올려요. 이미 찍은 영상이 있으면 파일을 주고 "이 영상 위에 효과를 입혀 줘"라고 해도 돼요.

    배경을 투명하게 해서 알파 채널이 있는 영상(ProRes 4444 .mov 또는 WebM)으로도 뽑아 줘.

초 단위로 보기

데모가 몇 초에 무엇을 보여 주는지예요. 장면을 따라 하려는 게 아니라, 기법이 어떤 순서와 리듬으로 쓰였는지 보는 용도예요.

따뜻한 종이 위에 크기가 다른 정사각 타일(120·60·30·15px)이 화면 전체에 깔려 있다. 타일마다 반지름 s/2의 사분원 실이 대각 두 모서리를 감싼다(스미스 트루셰 타일). 큰 타일의 실은 가운데 선과 가는 바깥 선 둘, 세 가닥 띠다. 색은 잉크 남색, 종이, 녹 주황(액센트) 세 가지다.

  • 짜임 (0–0.85초): 어둠에서 순수한 무작위 짜임이 떠오른다. 몇몇 타일이 혼자 반 바퀴 돌며(살짝 들렸다 내려앉음) 짜임이 살아 있음을 알린다.
  • 첫 물결 (0.85–3.6초): 왼쪽 위에서 아래로 비스듬한 파면이 지나간다. 지나가는 타일은 하나씩 들려 시계 방향으로 90° 또는 180° 돌고, 오버슈트 뒤 제자리에 앉는다. 도는 동안 실은 녹 주황으로 빛나고, 앉은 뒤에는 그 빛이 꼬리처럼 사그라든다.
  • 도는 타일 안에서 잉크가 자기 모서리에서 부풀어 나온다. 이웃 타일들의 잉크가 같은 꼭짓점에서 함께 자라 원으로 맞물린다.
  • 파도가 지나가면 "이"와 "음"이 세로로 쌓인 낱말 이음이 남는다. 글자 가장자리는 사분원 호로 된 물결 테두리이고, 글자 안은 종이색 실이 고리로 닫혀 수놓은 듯하다. 잉크는 종이 위에 살짝 떠 있다(오른쪽 아래 그림자, 왼쪽 위 모서리의 엷은 빛).
  • 부제 "끊어진 것을 잇고".
  • 다시 짜기 (4.95–7.7초): 이번에는 가운데에서 바깥으로 퍼지는 고리 파면이다. 타일이 반시계 방향으로 돌며 이음의 잉크가 물러나고, 매듭의 잉크가 자란다. 두 낱말이 공유하는 칸은 그대로 남는다. 바탕 짜임도 새로 섞인다. 남는 낱말은 매듭이다.
  • 여운 (7.7–10초): 구성은 멈춰 있고, 바탕과 글자 속의 몇 타일만 가끔 반 바퀴 돌며 반짝인다. 부제 "이어진 것을 맺는다". 마지막 0.35초에 어둠으로 닫힌다.

원리

개발자용 구현 설명이에요(원작자 노트, MIT). 몰라도 만들 수 있지만, Claude에게 "이 원리 중 ○○만 써 줘"처럼 지시할 때 도움이 돼요.

기법과 원리
  • 타일 어휘: 호로 하는 마칭 스퀘어(5비트) (shaders.js:129 inkSdf)
  • 네 모서리(왼위·오위·오아래·왼아래)가 각자 반지름 s/2 사분원을 갖는다. 네 원은 변의 중점에서 맞닿고, 가운데의 오목한 별 모양 영역은 중심 비트를 따른다.
  • 중심 0이면 잉크 = 잉크 모서리 원들의 합집합(min|u−c|−½), 중심 1이면 잉크 = 종이 모서리 원들의 여집합(½−min|u−c|)이다. 둘 다 정확한 부호 거리라서 AA와 침식이 그대로 된다.
  • 모든 경계는 변 중점에서 변과 직각으로 만나는 사분원 호다. 한 변의 색은 그 변의 두 모서리 비트만으로 정해진다. 그래서 모서리를 공유하는 타일끼리는 중심 비트와 상관없이 늘 맞물린다. 중심 비트는 안장 경우(대각 모서리끼리 같은 색)를 가르는 데 쓴다(main.js:80 bitsOf).
  • 모서리 점유 → 쿼드트리 (main.js:55 lattice, main.js:67 buildLeaves)
  • Pretendard Black(OFL) 620px 글자를 textAlpha로 래스터한다. 15px 격자 꼭짓점(73×129)마다 점유율(주변 2×2 픽셀 평균 ≥ 0.5)을 낱말마다 구한다.
  • 120px 칸에서 출발해, 칸 안(테두리 포함)의 꼭짓점이 어느 한 낱말에서라도 다르면 15px까지 나눈다.
  • 그래서 15px보다 큰 잎은 두 낱말 모두에서 균일하고, 그 둘레의 모든 꼭짓점이 같은 색이다. 크기가 다른 타일이 만나는 T자 접합에서도 잉크가 어긋나지 않는다(카를슨의 날개 없이 얻는 형상/바탕 일관성).
  • 가장자리 세부는 15px 호로 나온다. 바탕에는 무작위 분할을 더해(main.js:21 P_SPLIT) 두 낱말의 윤곽이 처음 짜임에서 드러나지 않게 하고, 다중 스케일 결을 만든다.
  • 실(스미스 타일)과 90° 회전 (shaders.js:144 threads, main.js:87 orient)
  • 스미스 타일을 90° 돌리면 대각이 바뀐다(방향 o ↔ 1−o). 그래서 각 상태의 목표 방향에 1/4바퀴 1번이나 2번으로 닿는다(main.js:113-117).
  • 목표 방향: 경계 타일은 경계 모서리가 있는 대각을 골라 실이 글자 윤곽을 껴안게 한다. 글자 안은 체커보드 방향이라 호가 고리로 닫힌다. 바탕은 무작위다.
  • 도는 동안 바뀌는 잉크 (shaders.js:89-99, shaders.js:138 inkCov)
  • 각 낱말의 무늬는 "그 낱말이 바로 서는 휴지 각도"의 틀(vA, vB)에서 그려진다. 타일이 돌면 무늬도 함께 돌다가 정확히 똑바로 내려앉는다.
  • 잉크는 침식된 거리장으로 자란다: 회전 진행 35–95%에서 자기 모서리에서 부풀어 나온다. 다 자라면 타일 클립이 타일 밖 2.5px로 물러나 이음매가 생기지 않는다.
  • 두 낱말에서 같은 칸은 유지 표시(keep)를 달아 다시 자라지 않는다. 그 칸이 비균일이면 아예 돌지 않는다.
  • 물결 일정 (main.js:118-120): 각 타일의 시작 = 파면 거리(첫 물결은 비스듬한 직선 투영, 둘째는 중심에서의 반지름) + 0–0.14초 흔들림이다. 큰 타일은 조금 더 오래 돈다(무게감). 오버슈트 이즈 1 + 2.6x³ + 1.6x²(shaders.js:63)로 약 10% 지나쳤다가 돌아온다.
  • 렌더링 (WebGL2, 인스턴스 한 버퍼) (main.js:259 draw) 1. 멈춘 타일 → 오프스크린 층(R 잉크, G 실, B 액센트). MAX 블렌딩이라 반 픽셀 겹침이 두 번 칠해지지 않아 타일 이음매가 없다. 2. 잉크를 절반 해상도로 블러한다(main.js:275-276). 3. 종이 + 그림자(블러 잉크를 (4, 7)px 오른쪽 아래로) + 엷은 경사광(블러 잉크의 기울기) + 실 → 화면(shaders.js:216 COMP_FS). 4. 도는 타일은 들린 카드로 위에 그린다. 들린 정도에 따라 커지고 흐려지는 그림자를 먼저 그리고, 카드는 깊이 버퍼로 높이 순서를 맞춘다(shaders.js:111). 정점 셰이더가 "도는 중"인지 판단해 각 패스에서 나머지를 퇴화시킨다.
  • 화면 아래(자막 자리)는 깊은 남색으로 가라앉는다(shaders.js:41). 흰 자막이 읽힌다.
  • 글줄 (main.js:170 drawText): 2D 캔버스 Pretendard 600 38px. 종이색 후광 획으로 뒤의 실을 눌러 읽힘을 지키고, 그 위에 녹 주황 짧은 괘선을 둔다.
프레임마다 같은 그림이 나오게 하는 법 (결정성)
  • 배치, 격자, 쿼드트리, 타일 비트, 실 방향, 파면 지연, 반짝임 일정은 setup에서 rand(5505) 한 줄기로 한 번 정해 인스턴스 버퍼에 굽는다.
  • frame(t)는 유니폼 t 하나만 바꾼다. 각 타일의 각도, 들림, 잉크 성장, 액센트 꼬리는 정점 셰이더에서 t의 닫힌식으로 계산한다(shaders.js:69-108). 이전 프레임 상태가 없다.
  • 그레인만 프레임 번호 round(t·30)으로 시드한다.

  • 한계
  • 잉크는 크기가 달라도 맞물리지만, 실은 크기가 다른 타일의 T자 접합에서 이어지지 않는다(큰 타일의 실 끝은 변 중점, 작은 타일은 1/4 지점). 다중 스케일 결로 읽히도록 실을 옅게 두었다. 카를슨의 날개 타일로 바꾸면 실까지 이어진다.
  • 글자 가장자리는 15px 격자로 양자화된 호의 물결이다. 가는 획이나 작은 받침에는 거칠다. FINE을 10px로 줄이면 세밀해지지만 타일 수가 늘어난다.
  • 잎은 수천 개(대부분 15px)이고 인스턴스 한 번에 그린다. 도는 타일 패스 둘도 전체 인스턴스를 돌리지만, 정점 셰이더가 거의 모두를 퇴화시켜 비용이 작다.
