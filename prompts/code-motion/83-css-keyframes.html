활용 가이드

배경·분위기로 쓸 때

글자나 제품 뒤에 깔리는 배경, 분위기를 잡는 오프닝·엔딩에 써요.

  • 배경은 주인공보다 어둡거나 덜 선명하게. 대비가 강하면 글자가 안 읽혀요.
  • 루프로 만들어 두면 여러 영상에 재사용할 수 있어요.
  • 무거운 셰이더 배경은 미리 렌더링해 영상 파일로 깔면 편해요.

만드는 법

  1. 준비하기

    Claude Code를 열고 빈 폴더에서 시작해요. aimotion 스킬을 처음 한 번 설치해요.

    claude plugin marketplace add kstost/cokacmotion claude plugin install aimotion@aimotion

  2. 프롬프트 만들기

    칸을 채우면 아래 프롬프트가 바로 바뀌어요. 데모의 장면이 아니라 내 장면을 적는 게 핵심이에요.

  3. 미리보기 보고 고치기

    Claude Code가 만든 HTML을 브라우저로 열어 확인하고, 고칠 점을 말로 알려 줘요. 자주 쓰는 수정 문장을 눌러 복사하세요.

  4. MP4로 뽑기

    실시간 화면 녹화보다 프레임 단위 렌더링이 끊김 없고 선명해요.

    이제 render(t)로 1/30초마다 프레임을 캡처해서 30fps MP4로 렌더링해 줘. 결과 파일 이름은 out.mp4로.

  5. 내 영상에 합치기

    제목 · 자막 · 전환처럼 실사 위에 얹을 효과라면 배경을 투명하게 뽑아 편집 프로그램(캡컷 · 프리미어)의 위 트랙에 올려요. 이미 찍은 영상이 있으면 파일을 주고 "이 영상 위에 효과를 입혀 줘"라고 해도 돼요.

    배경을 투명하게 해서 알파 채널이 있는 영상(ProRes 4444 .mov 또는 WebM)으로도 뽑아 줘.

초 단위로 보기

데모가 몇 초에 무엇을 보여 주는지예요. 장면을 따라 하려는 게 아니라, 기법이 어떤 순서와 리듬으로 쓰였는지 보는 용도예요.

10초, 1080×1920. 산이 겹겹이 선 호숫가의 해돋이를 밝은 그라디언트 일러스트로 그린다. 캔버스·셰이더·이미지 파일이 없고, 모든 픽셀은 CSS(그라디언트, clip-path 다각형, 블렌드 모드, 필터, offset-path)다.

  • 0–2.5초, 새벽 전: 보랏빛 밤하늘에 별이 깜박이고, 오른쪽 위에 그믐달이 진다. 접혀 누워 있던 산등성이 네 겹이 먼 것부터 차례로 일어서며 모양을 잡는다(다각형 꼭짓점 보간, 살짝 넘쳤다가 자리 잡는 이징). 맨 앞 물가에는 소나무 실루엣이 있다.
  • 2.5–5초, 첫 빛: 하늘이 남색 → 자주 → 산호색으로 바뀌고, 가느다란 구름이 산보다 먼저 분홍빛을 받는다. 가운데 골짜기에서 붉은 해가 오른다. 해무리 반경이 커지고, 원뿔 그라디언트 햇살 두 겹이 서로 반대로 돌기 시작한다.
  • 5–7.5초, 절정: 해가 금빛에서 흰빛으로 바뀌며 높이 뜬다. 해를 향한 비탈마다 빛을 받은 면(삼각형 패싯)이 자라나고, 골짜기의 안개가 빛난다. 새 다섯 마리가 해 앞을 가로질러 오른쪽 위로 날아간다. 호수에는 장면 전체가 거꾸로, 흐릿하게 비치고, 해 아래로 반짝이는 윤슬 길이 생긴다.
  • 6.35초~: "오늘도 해는 뜬다"(고운바탕 700)가 글자마다 흐림 속에서 떠오른다. 그 아래 가는 선이 펼쳐진다.
  • 8–10초, 아침: 하늘은 맑은 파랑, 산은 하늘빛 청록으로 가라앉는다. 햇살은 잦아들고 새는 화면 밖으로 나간다. 왼쪽 위 시계는 내내 오전 5:42에서 6:40으로 간다. 호수 아래쪽은 늘 어두워, 하네스 자막이 밝은 장면 위에서도 읽힌다.

원리

개발자용 구현 설명이에요(원작자 노트, MIT). 몰라도 만들 수 있지만, Claude에게 "이 원리 중 ○○만 써 줘"처럼 지시할 때 도움이 돼요.

기법과 원리

1. 등록된 커스텀 속성(@property)과 하나의 색 대본 - 하늘 네 색, 산 네 겹의 위·아래·안개빛, 빛 면 색, 안개, 구름, 해와 해무리, 물빛, 새 색, 시계: 37개를 @property로 <color>·<length>·<angle>·<integer> 타입 등록했다(style.css:17–style.css:53). - 등록되지 않은 커스텀 속성은 키프레임 사이에서 보간되지 않고 뚝 바뀐다. 타입이 있어야 브라우저가 값을 보간하고, 그 값을 쓰는 그라디언트가 매 프레임 다시 그려진다. - 이 색들은 .world 하나에 걸린 @keyframes palette(style.css:56) 한 개가 바꾼다. 등록할 때 inherits: true로 두어 모든 레이어와 반사 사본이 같은 값을 물려받는다. 이 키프레임이 작품 전체의 색 대본이다 (0% 밤, 18%, 36% 첫 빛 style.css:81, 52% 일출 style.css:95, 68%, 85% 아침 style.css:123, 100%). - 해무리 반경 --glow-r(<length>)는 radial-gradient의 색 정지 위치로 들어간다(style.css:188). - 햇살은 repeating-conic-gradient(from var(--ray-rot), …) 두 겹이다. 시작 각 --ray-rot(<angle>)를 @keyframes spin이 돌린다(style.css:199). 둘째 겹은 calc(var(--ray-rot) * -0.62)로 반대로 돈다. 각 겹의 빛줄기 폭 --ray-w도 <angle>이다(style.css:192). - 시계는 <integer> 두 개(--hh, --mm)를 counter-reset에 넣고, ::after { content: counter(hh) ":" counter(mm, decimal-leading-zero) }로 보인다 (style.css:303, 키프레임 style.css:309).

2. clip-path 다각형 보간 (ridges.js) - 산등성이는 조절점 몇 개를 결정적 난수(rand(seed))로 잘게 나누고 흔들어 만든 polygon()이다. 맨 앞 줄에는 소나무 열여섯 그루의 꼭짓점을 끼워 넣었다(ridges.js:25). - @keyframes ridge-N(ridges.js:108)은 "접힌" 다각형(모든 점을 바닥선 쪽으로 당긴 것, fold)에서 완성된 다각형으로 간다. 두 다각형의 꼭짓점 수가 같아서 브라우저가 점마다 보간한다. 이징 cubic-bezier(.22, 1.28, .36, 1)은 y가 1을 넘으므로 산이 살짝 솟았다가 내려앉는다. - 빛 받는 면(facetLine, ridges.js:79): 해(x=540)를 향해 내려가는 비탈마다 삼각형 하나를 만든다. 꼭대기 아래로 깊이를 주고 골짜기에서 0이 되는 띠다. 이 띠를 두 번째 다각형 애니메이션 lit-N(ridges.js:117)이 넓이 0에서 키운다. 띠는 mix-blend-mode: screen으로 산의 색 위에 얹힌다. 산 요소의 clip-path가 쌓임 맥락을 만들므로, 이 블렌드는 그 산 안에서만 일어난다.

3. 블렌드·필터 - 해무리와 햇살은 screen으로 섞는다. 안개 띠는 부드러운 radial 덩어리들이고, 두 겹은 screen, 한 겹은 따뜻한 soft-light다(style.css:222). 안개에서 블러 필터는 뺐다. 그라디언트 덩어리가 이미 부드러워서 같은 모양이 비용 없이 나온다. - 미세한 입자감: 정적인 SVG feTurbulence 데이터 URI 타일을 overlay로 7% 얹는다(style.css:317). 애니메이션은 없다.

4. 새: offset-path (style.css:274) - 새마다 offset-path: path('…')(무대 좌표, main.js:28)를 따라 offset-distance 0→100%로 날고, offset-rotate: auto로 길을 따라 기운다. 크기(scale)는 멀어지며 줄어든다. - 날개는 ::before/::after의 border-top 호다. rotate 키프레임이 무한 반복하며 퍼덕인다(style.css:285). 새마다 위상(--wing)과 주기(--flap)가 다르다.

5. 호수: 장면을 복제한 반사 (main.js:111, style.css:237) - setup에서 .scene의 자식들을 cloneNode로 복제해 .mirror에 넣는다. 같은 클래스이므로 같은 애니메이션이 같은 --t에서 돈다. transform: scaleY(-1)(물가선 기준)으로 뒤집고 filter: blur(2.6px)로 흐린다. 햇살 레이어는 반사에서 뺐다. - 물결 줄: 줄무늬 평면을 perspective 안에서 rotateX(70deg)로 눕혀, 줄 간격이 수평선 쪽으로 좁아지게 했다. soft-light로 섞는다(style.css:241). - 윤슬: 사다리꼴 clip-path 안의 짧은 가로 줄무늬다(style.css:249). 두 겹 줄무늬가 서로 다른 속도로 흘러 반짝인다. 마스크 두 장을 mask-composite: intersect로 겹친다. 하나는 해의 반사 위치 --gy(<length>, 해의 상승과 같은 키프레임)를 중심으로 한 radial, 다른 하나는 세로 틈이다.

프레임마다 같은 그림이 나오게 하는 법 (결정성)
  • 시계 하나: 모든 애니메이션에 animation-play-state: paused와 animation-delay: calc(var(--phase, 0s) - var(--t) * 1s)가 !important로 걸려 있다(style.css:13, 가상 요소 포함). frame(t)는 .sunrise에 --t만 쓴다(main.js:124).
  • 멈춘 애니메이션의 현재 시간은 0이므로, 지역 시간 = 0 − 지연 = t − 시작 시각이다. 지연이 바뀌어도 애니메이션은 다시 시작하지 않는다. 설령 브라우저가 애니메이션을 새로 만들더라도 지연만으로 위치가 정해지므로, 그림은 --t의 순수 함수다.
  • 타임라인 애니메이션은 모두 10초 길이다(키프레임 % = 초 × 10). 반복 애니메이션(별, 날개, 줄무늬)은 --phase로 시작 시각을 준다.
  • 난수(별 위치, 능선 흔들림)는 rand(seed)로 setup에서 한 번 만든다. JS는 매 프레임 스타일 값을 계산하지 않는다.
  • 헤드리스 수치 점검(스크린샷 없음): t를 0 → 5 → 2.5 → 10 → 7 → 1 순서로 바꾸며 getComputedStyle을 읽었다. --s0, 해 위치, --ray-rot, --glow-r, clip-path 꼭짓점, 새 offset-distance, 글자 opacity, 시계, 반사 사본의 값이 모두 t에 맞게 바로 반영되었다. 같은 t를 다시 읽으면 같은 값이었고, 반사 사본은 원본과 같았다.
한계와 조절할 점
  • 색 대본(시각별 하늘·산·빛): style.css:56의 키프레임 일곱 개.
  • 해의 상승 시각과 높이: style.css:183 (--gy도 같이 바꿀 것: @keyframes gy).
  • 햇살 회전량: style.css:199. 빛줄기 개수(주기 15°/9°): style.css:192.
  • 산 모양·접힘 정도·일어서는 시각·빛 면 깊이: ridges.js:15의 RIDGES(pts, fold, rise, facet, facetMax). 소나무 위치·높이: ridges.js:25.
  • 새 경로·시작·크기·날갯짓: main.js:28. 구름: main.js:37. 별 개수: main.js:48.
  • 문장과 등장 시각: main.js:24–main.js:25. 글꼴·크기: style.css:289. 등장 모양: style.css:294.
  • 반사 흐림·불투명도: style.css:237. 물결 줄의 기울기와 간격: style.css:241 이하. 자막 아래 어두운 물: style.css:269.
  • 성능 손잡이: 반사의 blur를 줄이거나 없애면(style.css:237) 가장 크게 가벼워진다. 다음으로 물결 평면(.ripples)과 윤슬 마스크가 크다.
  • 한계: 해와 햇살은 산 뒤에 있으므로 산에 가려진 쪽 빛줄기는 산 위로 새어 나오지 않는다(빛 산란 표현 없음). 윤슬과 반사는 실제 물리 반사가 아니라 거울 사본과 줄무늬다.
