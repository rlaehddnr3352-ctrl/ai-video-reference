제품·앱 소개로 쓸 때

제품·앱·서비스의 생김새나 기능을 보여 주는 장면에 써요.

  • 실제 제품 사진(배경 제거 PNG)이나 앱 화면 캡처를 함께 주면 그대로 넣어 움직여요.
  • 기능 하나당 2–3초, 한 화면에 한 가지만 보여 주세요.
  • 가격·혜택 같은 숫자는 코드로 넣어야 깨지지 않아요.

정보·데이터로 쓸 때

숫자·과정·경로·비교처럼 말로 설명하기 어려운 정보를 보여 줄 때 써요.

  • 실제 숫자와 출처를 표로 주세요. AI가 숫자를 지어내지 않게 '주어진 값만 쓰라'고 적어요.
  • 한 화면에 수치 하나, 결론 숫자는 크게.
  • 그래프는 마지막 값에서 1초 멈춰야 기억에 남아요.

만드는 법

  1. 준비하기

    Claude Code를 열고 빈 폴더에서 시작해요. aimotion 스킬을 처음 한 번 설치해요.

    claude plugin marketplace add kstost/cokacmotion claude plugin install aimotion@aimotion

  2. 프롬프트 만들기

    칸을 채우면 아래 프롬프트가 바로 바뀌어요. 데모의 장면이 아니라 내 장면을 적는 게 핵심이에요.

  3. 미리보기 보고 고치기

    Claude Code가 만든 HTML을 브라우저로 열어 확인하고, 고칠 점을 말로 알려 줘요. 자주 쓰는 수정 문장을 눌러 복사하세요.

  4. MP4로 뽑기

    실시간 화면 녹화보다 프레임 단위 렌더링이 끊김 없고 선명해요.

    이제 render(t)로 1/30초마다 프레임을 캡처해서 30fps MP4로 렌더링해 줘. 결과 파일 이름은 out.mp4로.

  5. 내 영상에 합치기

    제목 · 자막 · 전환처럼 실사 위에 얹을 효과라면 배경을 투명하게 뽑아 편집 프로그램(캡컷 · 프리미어)의 위 트랙에 올려요. 이미 찍은 영상이 있으면 파일을 주고 "이 영상 위에 효과를 입혀 줘"라고 해도 돼요.

    배경을 투명하게 해서 알파 채널이 있는 영상(ProRes 4444 .mov 또는 WebM)으로도 뽑아 줘.

초 단위로 보기

데모가 몇 초에 무엇을 보여 주는지예요. 장면을 따라 하려는 게 아니라, 기법이 어떤 순서와 리듬으로 쓰였는지 보는 용도예요.

미술관 도록처럼 차분한 화면이다. - 바탕은 옅은 회백(#efece6)이다. - 카드(3:4)는 위쪽 62%가 그 절기의 색면이고, 색면 안에 작은 SVG 모티프와 번호가 있다. - 카드 아래쪽에는 한글 이름(Noto Serif KR 700), 한자(Noto Serif KR 400), 양력 날짜(Pretendard)가 있다. - 위에는 二十四節氣와 부제, 오른쪽에 도판 번호(PL. 01 · GRID → … → PL. 05 · DETAIL)가 있고, 배치가 바뀔 때마다 마스크 안에서 갈아 끼워진다. - 아래에는 각주와 자막용 먹색 띠(y ≥ 1672)가 있다.

시간 배치 내용
0.1–1.6 격자(CSS grid 6×4) 한 줄이 한 계절이다. 카드가 왼쪽 위에서 대각선 물결로 떠오르고, 줄마다 "봄 · 春 입춘 — 곡우" 라벨이 붙는다.
1.6–3.3 바퀴(absolute + rotate) 입춘이 12시에 오고 시계 방향으로 돈다. 카드 머리가 바깥을 향하는 연륜이다. 안쪽 원이 그려지고, 절기마다 눈금, 사분면마다 계절 이름, 가운데 "한 해 · 15° × 24"가 나온다. 바퀴는 머무는 동안 −12° 돈다.
3.3–5.8 해의 길(flex 한 줄) 카드의 높이가 그 절기의 태양 고도 sin(황경)를 따른다. 하지가 가장 높고 동지가 가장 낮다. 카드 중심을 잇는 해의 길 곡선이 그려지고, 월 눈금자와 하지·동지 주석이 붙는다. 줄 전체가 입춘에서 대한까지 옆으로 흐른다(2692 px 팬).
5.8–7.2 계절(grid 셀 겹치기) 2×2 칸에 계절마다 여섯 장이 부채처럼 겹친 더미가 된다. 네 더미가 동시에 아래에서부터 쌓이고, 더미마다 "봄 春 / 입춘 — 곡우 · 2월 — 5월" 라벨이 붙는다.
7.2–10 입춘 입춘 카드가 봄 더미에서 빠져나와 페이지 가운데로 들려 오른다. 나머지 23장은 아래 색인 띠로 접혀 들어가고, 입춘 자리에는 빈 칸 표시가 남는다. 카드가 936×1248 도록 페이지로 펼쳐진다: 색면, 큰 새싹 모티프, "입춘 立春", "2월 4일 무렵 · 황경 315° · 스물넷 가운데 첫째", "봄이 문턱을 넘는 날. / 언 땅이 풀리고, 한 해가 다시 놓인다." 마지막으로 붉은 "立春大吉" 낙관이 찍힌다.

원리

개발자용 구현 설명이에요(원작자 노트, MIT). 몰라도 만들 수 있지만, Claude에게 "이 원리 중 ○○만 써 줘"처럼 지시할 때 도움이 돼요.

기법과 원리
  • 진짜 CSS 레이아웃 다섯 개(main.js:106-116): 같은 덱(.deck)에 붙는 클래스만 바뀐다.
  • L-grid: display: grid, 6열.
  • L-wheel: 카드마다 position: absolute 후 rotate(var(--a)) translateY(-360px).
  • L-row: display: flex. 카드마다 top: var(--alt)로 상대 위치를 주며, --alt = −110·sin(황경)이다(main.js:166).
  • L-stack: 2×2 grid에서 같은 칸(grid-row/column: var(--gr/--gc))에 여섯 장을 겹치고, --k로 이동·회전해 부채꼴로 편다.
  • L-strip: flex 띠.
  • 장식 SVG와 레이어는 position: absolute라 흐름에 끼지 않는다.
  • Flip.getState로 상태를 기록한다(main.js:174-181): setup에서 덱에 레이아웃 클래스를 차례로 붙이고, 그때마다 Flip.getState(cards)로 카드 24장의 경계·행렬을 기록한다. 장식 배치를 위해 무대 좌표도 함께 잰다. 그다음 덱을 기준 레이아웃(격자)으로 되돌린다.
  • Flip.fit(getVars)로 변환을 계산한다(main.js:204-217):
  • Flip.fit(card, state, { getVars: true, scale: true })는 카드를 그 상태의 자리에 맞추는 x, y, rotation, skewX, scaleX, scaleY를 돌려준다. 값은 기준에 대한 상대값이고, DOM은 원래대로 되돌린다.
  • 무대 자체의 CSS 배율(창 맞춤)은 Flip이 부모 행렬의 역행렬로 지워 준다.
  • 회전은 (−180°, 180°]로 나오므로 바퀴로 갈 때 카드가 가까운 쪽으로 돈다.
  • 들어 올릴 자리는 보이지 않는 고스트 요소에 맞춘다(main.js:184, main.js:212).
  • 중첩 공유 요소 모핑(main.js:213-216, main.js:360-365):
  • 입춘을 들린 자세로 잠시 놓고(gsap.set), 페이지의 각 부분을 작은 카드의 해당 부분에 Flip.fit해 시작 변환을 얻는다. 페이지 판(색면 포함)은 카드 전체에, 모티프·이름·한자는 각각 작은 카드의 것에 맞춘다.
  • 펼칠 때 작은 카드와 페이지가 0.1초 교차한다. 판은 power3.inOut, 안의 부분들은 0.04/0.07/0.1초 늦게 power4.inOut으로 따로 날아가므로, 부모와 자식이 다른 곡선으로 움직이는 중첩 Flip이 된다.
  • 스태거 전환(main.js:298-301): move()가 카드마다 fromTo(이전 변환 → 다음 변환)을 각자의 지연으로 넣는다.
  • 격자 입장은 (행+열)×0.045초의 대각선이다(main.js:316-319).
  • 바퀴·줄은 번호 순이다(main.js:325, main.js:335).
  • 계절 더미는 (k·0.03 + 계절·0.04)로 네 더미가 함께 쌓인다(main.js:350).
  • 띠는 0.008초 간격이다(main.js:358).
  • 덱 자체의 움직임:
  • 바퀴가 머무는 동안 덱이 (540, 900)을 축으로 −12° 돌고, 다음 전환에서 0으로 돌아온다(main.js:329, main.js:334).
  • 해의 길 팬은 덱의 x를 움직인다(main.js:340). 카드가 아직 날아드는 중에도 팬이 겹칠 수 있다.
  • 팬이 끝나는 순간 덱 x를 0으로 되돌리고, 그만큼 카드 x로 옮겨 준다. 보이는 위치는 변하지 않는다(main.js:343-345). 그래서 다음 전환이 스태거로 늦게 출발하는 카드도 제자리에 있다.
  • 장식(main.js:220-291): 모두 setup에서 잰 기하로 놓는다.
  • 계절 라벨은 격자 줄 첫 카드 위, 더미 라벨은 더미의 합집합 상자 위에 놓는다.
  • 바퀴 원은 stroke-dashoffset으로 그려진다.
  • 해의 길은 카드 중심을 Catmull-Rom 곡선(3차 베지에)으로 잇는다(main.js:258). 처음 보이는 화면만큼 먼저 그리고, 나머지는 팬과 같은 곡선으로 그려서 펜이 화면 오른쪽 끝을 따라간다(main.js:336-337).
  • 띠의 빈 칸은 L-strip에서 잰 입춘의 자리에 놓는다(main.js:291).
프레임마다 같은 그림이 나오게 하는 법 (결정성)
  • Flip은 setup에서만 쓴다.
  • Flip은 DOM을 재야 하므로 Flip.getState와 Flip.fit은 setup에서만 부른다. Flip.from은 쓰지 않는다.
  • Flip.from은 만들어지는 순간의 DOM을 끝 상태로 삼고 절대 위치 전환·clearProps를 콜백으로 처리하므로, 임의 seek에 기록 순서 의존성이 생긴다.
  • 타임라인에는 숫자 트윈만 있다.
  • 기록된 상태에서 뽑은 변환값(숫자)만 paused: true 마스터 타임라인의 fromTo로 넣는다(main.js:294).
  • frame(t)는 tl.time(t)만 한다(main.js:378-380). frame에서는 레이아웃을 읽지도 바꾸지도 않는다. 덱의 클래스는 늘 L-grid다.
  • from 값을 명시한다.
  • 각 요소·속성의 첫 트윈은 fromTo(immediateRender)다. 이후 전환은 이전 변환을 from으로 명시한 fromTo(immediateRender: false)다.
  • setup 끝에서 tl.time(D); tl.time(0)으로 모든 트윈을 재생 순서대로 초기화한다(main.js:374-375).
  • 한 시각에 같은 속성을 두 트윈이 다투지 않게 한다.
  • 팬 넘기기는 1 ms 트윈(길이 0인 set은 방향에 따라 달라짐)으로 한다.
  • 다음 전환은 그보다 2 ms 뒤에 시작한다(main.js:350). 그래서 5.8초(30 fps 프레임 위)를 앞에서 오든 뒤에서 오든 같은 그림이다.
  • 난수를 쓰지 않는다. 배치는 모두 CSS와 데이터에서 나온다.
한계와 조절할 점
  • 박자: main.js:24(T)에서 입장·바퀴·줄·팬·계절·들기·펼치기·정보·낙관 시각을 정한다.
  • 배치 기하:
  • 바퀴 반지름·카드 폭: main.js:90(WHEEL).
  • 줄 카드 폭·간격·태양 고도 진폭: main.js:91(ROW).
  • 레이아웃 CSS: main.js:106-116. 격자 위치는 padding, 더미 부채꼴은 9px / −10px / 2.4deg로 정한다.
  • 데이터: 절기 이름·한자·날짜·황경·색·모티프는 main.js:33-46, 모티프 SVG는 main.js:50-82에 있다. 날짜는 해마다 하루쯤 달라지는 대표값이다.
  • 전환 곡선과 스태거: 각 move(…, { dur, ease, delay }) 호출에서 바꾼다(main.js:325, 335, 350, 358). 중첩 모핑의 늦음과 곡선은 main.js:362-365에 있다.
  • 팬 속도: 2692 px를 1.9초에(T.scroll–T.scrollEnd) 움직이며, 정점 속도는 약 2800 px/s다. 더 느리게 하려면 ROW.w를 줄이거나 팬 시간을 늘린다.
  • 한계:
  • 카드 전환은 Flip처럼 직선 경로를 지난다(호를 따르지 않는다).
  • 덱 회전·팬과 겹치는 구간은 두 변환이 합성되므로 곡선 경로가 된다.
  • 들기 고스트는 페이지 중심에 맞췄다. 페이지 판과 작은 카드가 같은 3:4라 판은 균일 배율이다. 반면 이름·한자 상자는 글꼴 크기 비율이 미세하게 달라 scaleX ≠ scaleY가 아주 조금 섞일 수 있다.
