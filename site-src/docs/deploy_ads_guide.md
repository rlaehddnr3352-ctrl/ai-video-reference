# 공개 배포 · 광고 달기 안내

이 폴더 그대로 웹 호스팅에 올리면 바로 열리는 사이트입니다. 로그인이 필요 없고, 카드 데이터는 index.html 안에 들어 있습니다.

## 폴더 구성
- `index.html` — 레퍼런스 사전 본체 (카드 25개 + 구조·샷·앵글·조명 카드 포함, 광고 자리 3곳)
- `privacy.html` — 소개 · 개인정보처리방침 · 문의 (AdSense 심사에 필요)
- `ads.txt` — AdSense 승인 후 게시자 ID로 바꿔야 하는 파일
- `robots.txt` — 검색엔진 수집 허용

## 1. 도메인 준비
AdSense는 `ads.txt`를 **도메인 최상위(루트)** 에서 읽습니다. `xxx.web.app`, `xxx.github.io` 같은 무료 주소는 루트가 플랫폼 소유라 ads.txt를 둘 수 없으니, 개인 도메인(연 1–2만 원대)을 하나 사서 연결하는 게 안전합니다.

## 2. 올리기 (가장 쉬운 순)
1. **Netlify Drop** — 사이트에서 이 폴더를 끌어다 놓으면 끝. 이후 도메인 설정에서 산 도메인 연결.
2. **Cloudflare Pages** — 폴더 업로드로 배포, 도메인도 Cloudflare에서 사면 연결이 쉬움.
3. **Firebase Hosting** — 참고 사이트(.web.app)와 같은 방식. 명령어 설치가 필요해서 1·2보다 손이 더 감.

## 3. 올리기 전에 고칠 것
- `privacy.html`의 `[운영자 이름 또는 상호]`, `[문의 이메일 주소]`
- (선택) 카드 문구가 반려동물 사료 위주라, 일반 방문자용으로 넓히려면 말씀해 주세요.

## 4. AdSense 신청 후
1. 받은 게시자 ID(`ca-pub-숫자16자리`)로 `index.html`의 `ca-pub-0000000000000000`을 **모두 바꾸기**
2. `ads.txt`의 `pub-0000000000000000`도 같은 숫자로 바꾸기
3. 승인 뒤 광고 단위를 만들면 받는 숫자로 `index.html`의 `SLOT_TOP`, `SLOT_MID`, `SLOT_FOOT`를 바꾸기 → 그 자리만 광고가 켜집니다 (바꾸기 전에는 빈칸이 안 보임)
4. 자동 광고만 쓸 거면 3번은 건너뛰어도 됩니다.

## 참고
- 클로드 안에서 쓰는 버전과 달리, 공개 버전에는 **AI 예시 제안**이 기본 템플릿 컨셉으로만 나옵니다(방문자마다 AI를 호출하면 비용이 생기기 때문).
- 카드 추가 · 삭제는 공개 버전에 없습니다. 클로드 안의 보관함에서 카드를 늘린 뒤 다시 빌드하면 됩니다.
