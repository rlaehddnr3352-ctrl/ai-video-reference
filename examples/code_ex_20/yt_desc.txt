▶ 카드로 AI 영상 프롬프트 만드는 무료 사이트: https://ai-video-reference-kr.netlify.app/

영상 AI 없이, Claude에게 프롬프트를 주고 코드(HTML·Canvas·Three.js)로 그리게 만든 브랜드 스토리 영상 2편이에요. 영상 속 브랜드·숫자는 모두 지어낸 예시예요.

① 선이 그어지며 이어지는 브랜드 연혁 타임라인
바꿔 쓰는 법: 연도와 사건 5개, 마지막 한 줄만 바꾸면 돼요. 개인 이력이나 프로젝트 진행 과정도 같은 방식으로 넣을 수 있어요.

프롬프트 전문 ①
Create a 12-second vertical (1080x1920) brand-history timeline as one HTML file with Canvas 2D. Expose window.render(t) that draws the frame at time t (seconds) deterministically, so it can be recorded frame by frame.

Brand: [BRAND]. Milestones (year, event): [YEAR 1 — EVENT], [YEAR 2 — EVENT], [YEAR 3 — EVENT], [YEAR 4 — EVENT], [YEAR 5 — EVENT].

0–1s: title "[TITLE]" rises in at the top.
1–9.5s: a vertical line draws downward at x≈300 at a steady pace; when its tip reaches each milestone, a dot pops (back ease) with a ring pulse, the year counts/rolls in big on the left of the line, and an event card slides in from the right. The view slowly scrolls upward so the newest milestone stays around the middle; earlier ones dim to 50%.
9.5–12s: the last milestone glows; a closing line "[CLOSING LINE]" fades in; fade out.

Elegant editorial look: deep green background, cream text, gold accent for dots, serif for years (Noto Serif KR), sans for body.

② 행성처럼 도는 서비스 구성 3D 다이어그램
바꿔 쓰는 법: 가운데 이름과 주변 4개 항목, 색만 바꾸면 돼요. 제품 라인업(본품·리필·세트·굿즈)이나 서비스 기능 소개에도 그대로 쓸 수 있어요.

프롬프트 전문 ②
Create an 11-second vertical (1080x1920) 3D "ecosystem" orbit diagram as one HTML file using Three.js. Expose window.render(t) that sets the whole scene for time t (seconds) and renders one frame — no requestAnimationFrame clock — so it can be recorded frame by frame.

Center: [MAIN SERVICE]. Orbiting items (4): [ITEM 1], [ITEM 2], [ITEM 3], [ITEM 4], each with a color.

Scene: dark space background with a few hundred faint star points; a glossy central sphere with an emissive rim (Fresnel-like look via a slightly larger back-side transparent sphere); four smaller spheres on tilted orbit rings (thin line circles), each with different radius and speed.
2D labels: each frame, project every sphere's position to screen and draw a rounded label with its name next to it; labels of spheres behind the center get dimmer (use projected depth).
0–2s: the center sphere scales in; orbit rings draw in (opacity 0 → 1).
2–8s: planets appear one by one and orbit; the camera slowly tilts from a side view to a 30° top view.
8–11s: all planets align briefly for a 'family photo'; the title "[TITLE]" appears; fade out.

만든 영상을 mp4로 뽑을 땐 Claude에게 "render(t)로 초당 30장 캡처해서 mp4로 합쳐 줘"라고 하면 돼요.
